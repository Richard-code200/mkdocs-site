# Zed 快捷键笔记设计

## 目标

在 MkDocs 站点中新增 Zed 专题目录，完整记录本机 Zed 自定义快捷键，方便日常速查和后续维护。

## 文件结构

- `docs/Zed/index.md`：介绍本机 Zed 的基础键位和 Vim 模式，并提供快捷键手册入口。
- `docs/Zed/快捷键.md`：按使用场景整理全部自定义快捷键。

站点导航由 `docs/` 目录结构自动生成，不修改 `mkdocs.yml`。

## 内容结构

快捷键手册包含以下部分：

1. 配置概览与配置文件位置。
2. `Space` Leader 键、组合键和上下文等按键约定。
3. 高频快捷键速查表。
4. 全局窗格、文件保存、标签页和搜索操作。
5. LSP、Git、AI 和任务快捷键。
6. 项目面板、Git 面板、Agent 面板和终端快捷键。
7. Vim 普通、可视、插入模式增强，以及补全、代码操作和编辑预测快捷键。
8. 同一按键在不同上下文中的行为差异、外部任务依赖和潜在配置问题。

## 内容来源

- `~/.config/zed/keymap.json`
- `~/.config/zed/settings.json`

笔记只说明当前有效的自定义配置，不复制整份原始配置，也不把 Zed 默认快捷键误写成自定义快捷键。

## 验证标准

- 两个 Markdown 文件均可被 MkDocs 自动发现。
- 自定义绑定按配置文件逐项核对，无遗漏或错误归类。
- Markdown 表格和站内链接可正常构建。
- `mkdocs build` 成功完成。
