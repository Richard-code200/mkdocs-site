# 今日杂乱知识

## 概念简述

1. What does JDK stand for? What does IDE stand for?
   JDK和IDE代表着什么?
   A: JDK是Java的开发工具包,是一套独立的程序集合,每个程序都从命令行调用,用于开发和测试Java程序.
   IDE是集成开发环境,将编程,编译,连接,调试,和在线帮助都集成在一个图形用户界面中,用于快速开发应用程序.
2. What are the benefits of using constants?
   使用常量的好处有哪些?
   A:
   - 不必重复录入
   - 可以只修改定义语句(一改全改)
   - 可以赋常量一个有意义的名字,增加可读性

3. How is an argument passed to a method?
   Can the argument have the same name as its parameter?
   如何将一个参数传入一个方法(函数)?实际参数可以和形参有相同的名字吗?
   A: 按值传递,形参不改变实参. 按地址传递,形参会影响实参
   实参可以和形参有相同的名字

4. Describe the relationship between an object and its defining class.
   解释对象和它对应的类的关系.
   A: 对象是类的实例,类是对象的抽象

5. Describe the difference between method matching and method binding.
   说明方法匹配和方法绑定之间的不同.
   A: 方法匹配的是方法签名,是静态的,由编译器做,引用类型
   方法绑定确定执行方法的版本,是动态的,由JVM做,实际对象类型

6. What is the key word throw used for? What is the key word throws used for?
   关键词"throw"和"throws"分别是用来干什么的?
   A: throw抛出一个异常命令,throws再声明一个方法,在告诉系统可能抛出什么异常
