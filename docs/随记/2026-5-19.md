# 2026-5-19

## 概念简述

1. **What does JDK stand for? What does IDE stand for?**

   JDK 和 IDE 分别代表着什么？

   **A:**
   JDK 是 Java 的开发工具包，是一套独立的程序集合，每个程序都从命令行调用，用于开发和测试 Java 程序。
   IDE 是集成开发环境，将编程、编译、连接、调试和在线帮助都集成在一个图形用户界面中，用于快速开发应用程序。

2. **What are the benefits of using constants?**

   使用常量的好处有哪些？

   **A:**
   不必重复录入
   可以只修改定义语句（一改全改）
   可以赋常量一个有意义的名字，增加可读性

3. **How is an argument passed to a method? Can the argument have the same name as its parameter?**

   如何将一个参数传入一个方法（函数）？实际参数可以和形参有相同的名字吗？

   **A:** 按值传递，形参不改变实参；按地址传递，形参会影响实参。实参可以和形参有相同的名字。

4. **Describe the relationship between an object and its defining class.**

   解释对象和它对应的类的关系。

   **A:** 对象是类的实例，类是对象的抽象。

5. **Describe the difference between method matching and method binding.**

   说明方法匹配和方法绑定之间的不同。

   **A:**
   方法匹配的是方法签名，是静态的，由编译器做，引用类型
   方法绑定确定执行方法的版本，是动态的，由 JVM 做，实际对象类型

6. **What is the key word throw used for? What is the key word throws used for?**

   关键词 `throw` 和 `throws` 分别是用来干什么的？

   **A:** `throw` 抛出一个异常命令；`throws` 在声明一个方法时，告诉系统可能抛出什么异常。

7. **What is a comment? Is the comment ignored by the compiler? How do you denote a comment line and a comment paragraph?**

   注释是什么？注释会被编译器忽略吗？如何定义单行注释和多行注释？

   **A:**
   注释是用来标注程序是干什么用的，注释不被编译器编译。
   单行注释使用 `//` 表示
   多行注释使用 `/* */` 表示

8. **What does an explicit casting from a double to an int do with the fractional part of the double value? Does casting change the variable being cast?**

   将 double 显式转换为 int 时，小数部分会怎么处理？类型转换会改变被转换的变量本身吗？

   **A:** 将 double 显式转换为 int 类型会去除小数部分，对变量进行显式转换不会改变被修改的变量的类型或数值，只会产生新的值。

9. **What is the scope of a local variable?**

   局部变量的作用域是什么？

   **A:** 变量在程序中可起作用的范围叫作用域，从声明变量的位置开始到该变量所在代码块的结尾位置。

10. **What are the benefits of data field encapsulation?**

    数据字段封装的好处有哪些？

    **A:** 数据保护、灵活变更、统一控制、可维护性、线程安全。

11. **What are the benefits of @override annotation?**

    重写标注的好处有哪些？

    **A:**
    该标注表示被标注的方法必须是重写父类的一个方法
    如果具有该标注的方法没有重写父类的方法，将会报告编译错误
    所以使用该标注的好处是可以避免因写错而错误的方法

12. **What is declare exception? Why use it? How use it? Where should it be?**

    声明异常是什么？使用它的目的是什么？怎么用它？它应该放在哪？

    **A:** 在 Java 程序中，每个方法都必须声明它有可能抛出的必检异常的类型，这称为声明异常。声明异常应该在方法的头部。

    ```java
    public void theMethod()
      throws Exception
    ```
