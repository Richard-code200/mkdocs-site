# 工作区暂存

## 保存临时工作

```bash
# 临时保存当前工作区的修改
git stash

# 保存并添加描述信息
git stash push -m "描述信息"

# 保存未跟踪的文件
git stash push -u
git stash push --include-untracked

# 保存所有文件（包括被忽略的）
git stash push -a
git stash push --all
```

## 查看暂存列表

```bash
# 查看所有暂存列表
git stash list

# 输出示例：
# stash@{0}: On feature-login: 完成登录表单
# stash@{1}: On main: 临时保存
```

## 恢复暂存

```bash
# 恢复最近一次暂存，并从列表中移除
git stash pop

# 恢复指定暂存
git stash pop stash@{1}

# 恢复最近一次暂存，但保留在列表中
git stash apply

# 恢复指定暂存，保留在列表中
git stash apply stash@{1}
```

## 查看暂存内容

```bash
# 查看最近暂存的改动
git stash show

# 查看详细差异
git stash show -p

# 查看指定暂存的详细内容
git stash show -p stash@{1}
```

## 删除暂存

```bash
# 删除最近一次暂存
git stash drop

# 删除指定暂存
git stash drop stash@{1}

# 清除所有暂存
git stash clear
```

## 从暂存创建分支

```bash
# 从最近暂存创建新分支（解决恢复时冲突的好方法）
git stash branch <new-branch-name>

# 从指定暂存创建分支
git stash branch <new-branch-name> stash@{1}
```

## 常用工作流示例

```bash
# 场景：正在开发新功能，突然需要修复紧急bug

# 1. 保存当前工作
git stash push -m "feature-login 开发中"

# 2. 切换到主分支修复bug
git checkout main
git checkout -b hotfix/critical-bug
# ... 修复并提交 ...

# 3. 回到功能开发分支，恢复工作
git checkout feature-login
git stash pop
```
