# 标签管理

## 查看标签

```bash
# 列出所有标签
git tag

# 按模式搜索标签
git tag -l "v1.*"

# 查看标签详情
git show <tag-name>
```

## 创建标签

```bash
# 创建轻量标签（仅指针）
git tag <tag-name>
git tag v1.0.0

# 创建附注标签（推荐，包含作者、日期、信息）
git tag -a <tag-name> -m "标签说明"
git tag -a v1.0.0 -m "正式发布1.0.0版本"

# 为历史提交创建标签
git tag -a <tag-name> <commit-id> -m "标签说明"
```

## 操作标签

```bash
# 切换到标签（分离头指针状态）
git checkout <tag-name>

# 基于标签创建分支
git checkout -b <branch-name> <tag-name>

# 删除本地标签
git tag -d <tag-name>

# 重命名标签
git tag <new-name> <old-name>
git tag -d <old-name>
```

## 推送标签到远程

```bash
# 推送单个标签
git push origin <tag-name>

# 推送所有本地标签
git push origin --tags

# 删除远程标签
git push origin --delete <tag-name>

# 删除远程标签（旧版语法）
git push origin :refs/tags/<tag-name>
```

## 版本号命名规范（语义化版本）

```text
v主版本号.次版本号.修订号

v1.0.0    # 正式发布
v1.0.1    # 补丁更新
v1.1.0    # 功能更新
v2.0.0    # 重大变更（不兼容）
v1.0.0-alpha  # 内测版
v1.0.0-beta   # 公测版
v1.0.0-rc.1   # 候选发布版
```
