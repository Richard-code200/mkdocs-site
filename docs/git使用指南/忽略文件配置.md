# 忽略文件配置

## .gitignore 基本规则

```text
# 注释以 # 开头

# 忽略特定文件
secret.txt

# 忽略特定目录
node_modules/
build/
dist/

# 忽略特定扩展名
*.log
*.tmp
*.swp

# 忽略空目录（Git默认不跟踪空目录）
# 通常在各目录下放一个 .gitkeep 文件来占位
```

## 匹配模式

```text
# 通配符规则：

# * 匹配任意多个字符
*.log         # 忽略所有 .log 文件

# ? 匹配单个字符
access?.log   # 匹配 access1.log, access2.log 等

# [...] 匹配字符范围
file[0-9].txt # 匹配 file0.txt 到 file9.txt

# ** 匹配任意层级的目录
a/**/b        # 匹配 a/b, a/x/b, a/x/y/b 等

# 以 / 开头表示从仓库根目录匹配
/build        # 只忽略根目录下的 build，不忽略 src/build

# 以 / 结尾表示只匹配目录
build/        # 只忽略名为 build 的目录

# 以 ! 开头表示取反（不忽略）
*.log
!important.log  # 不忽略 important.log
```

## 常用 .gitignore 模板

```text
# 操作系统
.DS_Store     # macOS
Thumbs.db     # Windows

# IDE
.vscode/
.idea/
*.swp
*.swo

# 依赖
node_modules/
vendor/
.bundled/

# 构建输出
build/
dist/
out/
*.exe

# 环境配置
.env
.env.local
.env.*.local

# 日志
*.log

# 临时文件
*.tmp
*.temp
```

## 全局忽略配置

```bash
# 创建全局 .gitignore（对所有仓库生效）
git config --global core.excludesfile ~/.gitignore_global

# 向全局忽略文件添加规则
echo ".DS_Store" >> ~/.gitignore_global
```

## 忽略已被跟踪的文件

```bash
# 如果文件已经被 Git 跟踪，仅添加 .gitignore 不会生效
# 需要先将其从 Git 的跟踪中移除

# 停止跟踪但不删除文件
git rm --cached <filename>

# 停止跟踪整个目录
git rm -r --cached <directory>

# 然后提交更改
git commit -m "停止跟踪不再需要的文件"
```

## 查看忽略规则

```bash
# 查看哪些规则导致文件被忽略
git check-ignore -v <filename>

# 检查文件是否会被忽略
git check-ignore <filename>
```
