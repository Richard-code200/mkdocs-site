# 格式化输出

Rust 的格式化输出由 `std::fmt` 模块提供,通过宏来处理.

## 格式化宏家族

| 宏 | 输出目标 | 换行 |
| -- | -------- | ---- |
| `format!` | 返回 `String` | 无 |
| `print!` | 标准输出(stdout) | 无 |
| `println!` | 标准输出(stdout) | 有 |
| `eprint!` | 标准错误(stderr) | 无 |
| `eprintln!` | 标准错误(stderr) | 有 |
| `write!` | 指定的 `fmt::Write` | 无 |

```rust
let s = format!("Hello, {}!", "Rust");
println!("{s}");

eprintln!("这是一条错误信息");
```

### `format!` 与 `std::fmt::format`

`format!` 是日常代码使用的宏,直接接收格式字符串和参数并返回 `String`.`std::fmt::format` 是较底层的函数,参数类型为 `fmt::Arguments`,通常需要配合 `format_args!`:

```rust
let direct = format!("{} + {} = {}", 1, 2, 3);
let indirect = std::fmt::format(format_args!("{} + {} = {}", 1, 2, 3));

assert_eq!(direct, indirect);
```

一般优先使用 `format!`;只有 API 已经传递 `fmt::Arguments` 时才需要 `std::fmt::format`.两者都会生成拥有所有权的 `String`,不要把 `std::fmt` 模块名误当成 `format!` 宏的调用路径.

## 占位符语法

### 基本占位符 `{}`

```rust
println!("{} days", 31);
println!("{} months", 12i64);
println!("{} seconds", 5.11f64);
```

### 位置参数

```rust
println!("{0}, this is {1}. {1}, this is {0}", "Alice", "Bob");
```

### 命名参数

```rust
println!(
    "{subject} {verb} {object}",
    object = "the lazy dog",
    subject = "the quick brown fox",
    verb = "jumps over"
);
```

### 变量捕获

```rust
let name = "Rust";
let version = 2024;
println!("Hello {name}, edition {version}");
```

## 格式化说明符

在 `:` 后面指定特殊格式:

```rust
println!("{:b}", 2);     // 二进制: 10
println!("{:o}", 8);     // 八进制: 10
println!("{:x}", 255);   // 小写十六进制: ff
println!("{:X}", 255);   // 大写十六进制: FF
println!("{:e}", 100.0); // 科学计数法: 1e2
```

### 对齐与填充

```rust
println!("{:>5}", 1);      // 右对齐,宽度5: "    1"
println!("{:<5}", 1);      // 左对齐,宽度5: "1    "
println!("{:^5}", 1);      // 居中对齐:     "  1  "
println!("{:>05}", 1);     // 零填充:       "00001"
println!("{:*>5}", 1);     // 自定义填充:   "****1"
```

### 精度控制

```rust
println!("{:.2}", 3.14159);  // 保留2位小数: 3.14
println!("{:10.2}", 3.14);   // 宽度10,保留2位小数: "      3.14"
```

### 使用变量作为格式参数

```rust
println!("{number:>width$}", number = 1, width = 6);
println!("{number:>0width$}", number = 1, width = 6);
```

## Debug trait

`Debug` trait 用于调试输出,使用 `{:?}` 占位符:

```rust
println!("{:?} months in a year.", 12);
```

### 自动派生 Debug

使用 `#[derive(Debug)]` 自动实现:

```rust
#[derive(Debug)]
struct Structure(i32);

#[derive(Debug)]
struct Deep(Structure);

fn main() {
    println!("{:?}", Structure(3));
    println!("{:?}", Deep(Structure(7)));
}
```

### 美化打印

使用 `{:#?}` 进行多行美化输出:

```rust
#[derive(Debug)]
struct Person<'a> {
    name: &'a str,
    age: u8,
}

fn main() {
    let peter = Person { name: "Peter", age: 27 };
    println!("{:#?}", peter);
}
```

输出:

```
Person {
    name: "Peter",
    age: 27,
}
```

### dbg! 宏

`dbg!` 打印表达式及其值,并返回该值:

```rust
let scale = 2;
let rect = dbg!(30 * scale);  // 打印 "[src/main.rs:2] 30 * scale = 60"
dbg!(&rect);                  // 打印 "[src/main.rs:3] &rect = 60"
```

## Display trait

`Display` trait 用于面向用户的格式化输出,使用 `{}` 占位符.标准库类型已实现 `Display`,自定义类型需要手动实现:

```rust
use std::fmt;

struct Structure(i32);

impl fmt::Display for Structure {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{}", self.0)
    }
}

fn main() {
    println!("{}", Structure(3));
}
```

### 多字段结构体的 Display

```rust
use std::fmt;

#[derive(Debug)]
struct MinMax(i64, i64);

impl fmt::Display for MinMax {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "({}, {})", self.0, self.1)
    }
}

#[derive(Debug)]
struct Point2D {
    x: f64,
    y: f64,
}

impl fmt::Display for Point2D {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "x: {}, y: {}", self.x, self.y)
    }
}

fn main() {
    let minmax = MinMax(0, 14);
    println!("Display: {}", minmax);     // (0, 14)
    println!("Debug: {:?}", minmax);     // MinMax(0, 14)

    let point = Point2D { x: 3.3, y: 7.2 };
    println!("Display: {}", point);      // x: 3.3, y: 7.2
    println!("Debug: {:?}", point);      // Point2D { x: 3.3, y: 7.2 }
}
```

/// info | Display vs Debug

| | Display `{}` | Debug `{:?}` |
| ---- | ------------ | ------------ |
| 用途 | 面向用户 | 面向开发者 |
| 实现 | 必须手动实现 | 可 `#[derive(Debug)]` |
| 格式 | 自定义 | 自动生成 |
| 适用 | 最终输出 | 调试打印 |
///

/// warning | 不能同时使用 Display 和 Debug 以外的格式
`{:b}` 需要实现 `fmt::Binary`,`{:x}` 需要实现 `fmt::LowerHex`.只实现了 `Display` 和 `Debug` 的类型不能使用这些格式.
///

## 注释

### 行注释

```rust
// 这是行注释
// 编译器会忽略 // 后面的所有内容
```

### 块注释

块注释支持**嵌套**:

```rust
/* 这是块注释
 * 可以跨越多行
 * /* 块注释可以嵌套 */ */
```

块注释可以嵌入表达式中:

```rust
let x = 5 + /* 90 + */ 5;
println!("x = {x}"); // x = 10,而非 100
```

/// important | 格式化输出核心要义
`Debug` 用于开发调试(`{:?}`),`Display` 用于用户展示(`{}`).大多数自定义类型先 `#[derive(Debug)]` 快速调试,需要面向用户输出时再手动实现 `Display`.
///
