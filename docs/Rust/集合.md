# 集合

Rust 标准库提供了多种可以在运行时增长或缩小的集合类型.本章只介绍 `Vec<T>` 和 `String`,示例参考 `Rust_Lang/collections_learn/src/main.rs` 的最终代码.

## Vec<T>

`Vec<T>` 是可变长度的连续序列.同一个 `Vec<T>` 中的元素必须具有相同类型.

### 创建与更新

可以使用 `Vec::new()` 创建空向量.空向量没有可供编译器推断的元素,通常需要标注类型:

```rust
let v: Vec<i32> = Vec::new();
```

已有初始值时,可以使用 `vec!` 宏:

```rust
let v = vec![1, 2, 3];
```

向量必须声明为可变才能调用 `push` 添加元素:

```rust
let mut v = Vec::new();
v.push(5);
v.push(6);
v.push(7);
v.push(8);
```

这里不需要显式写出 `Vec<i32>`,因为第一次 `push` 后编译器可以推断元素类型.

### 使用索引与 get 读取元素

读取向量元素有两种常见方式:

```rust
let v = vec![1, 2, 3, 4, 5];

let third: &i32 = &v[2];
println!("The third element is {third}");

match v.get(2) {
    Some(third) => println!("The third element is {third}"),
    None => println!("There is no third element"),
}
```

- `&v[index]` 返回元素引用,索引越界时程序会 panic.
- `v.get(index)` 返回 `Option<&T>`,可以显式处理不存在的元素.
- 索引从 `0` 开始,所以索引 `2` 对应第三个元素.

/// warning | 不确定索引是否有效时使用 get
来自用户输入、文件或计算结果的索引可能越界.此时应优先使用 `get`,不要让一次普通查询导致整个程序 panic.
///

### 共享迭代与可变迭代

使用 `&v` 迭代会共享借用向量,每次得到 `&T`,不会获取元素所有权:

```rust
let v = vec![100, 32, 57];

for i in &v {
    println!("{i}");
}

println!("元素数量: {}", v.len());
```

使用 `&mut v` 迭代会可变借用向量,每次得到 `&mut T`.修改元素前需要使用 `*` 解引用:

```rust
let mut v = vec![100, 32, 57];

for i in &mut v {
    *i += 50;
}

println!("{v:?}"); // [150, 82, 107]
```

/// info | 三种迭代方式
`for item in &v` 读取元素,`for item in &mut v` 修改元素,`for item in v` 消耗向量并取得元素所有权.是否还要继续使用 `v`,决定了应选择哪一种方式.
///

### 使用 enum 保存异构数据

向量的所有元素必须是同一种类型.如果一组数据存在几种确定的形态,可以定义一个枚举,让不同数据成为同一枚举类型的变体:

```rust
enum SpreadsheetCell {
    Int(i32),
    Float(f64),
    Text(String),
}

let row = vec![
    SpreadsheetCell::Int(3),
    SpreadsheetCell::Text(String::from("blue")),
    SpreadsheetCell::Float(10.12),
];
```

`row` 的类型是 `Vec<SpreadsheetCell>`.处理元素时可以使用 `match` 穷尽每一种变体:

```rust
for cell in &row {
    match cell {
        SpreadsheetCell::Int(value) => println!("整数: {value}"),
        SpreadsheetCell::Float(value) => println!("浮点数: {value}"),
        SpreadsheetCell::Text(value) => println!("文本: {value}"),
    }
}
```

这种方式适用于数据形态在编译时已知的情况,并且编译器会检查是否遗漏某个变体.

## String

`String` 是拥有所有权、可增长且使用 UTF-8 编码的字符串类型.字符串字面量的类型则是 `&str`.

### 创建 String

常见创建方式如下:

```rust
let data = "initial contents";

let s1 = data.to_string();
let s2 = "initial contents".to_string();
let s3 = String::from("initial contents");
```

三者都创建拥有内容所有权的 `String`.`to_string()` 可用于实现了 `Display` 的值,从字符串字面量创建时与 `String::from` 效果相同.

### 追加字符串与字符

`push_str` 接受 `&str`,不会取得参数的所有权:

```rust
let mut s1 = String::from("foo");
let s2 = "bar";

s1.push_str(s2);
println!("s1 is {s1}"); // foobar
println!("s2 is {s2}"); // s2 仍然有效
```

`push` 每次追加一个 `char`:

```rust
let mut s = String::from("lo");
s.push('l');

assert_eq!(s, "lol");
```

### 使用 + 与 format! 拼接

`+` 运算符左侧必须是 `String`,右侧通常传入 `&str`:

```rust
let s1 = String::from("Hello, ");
let s2 = String::from("world!");
let s3 = s1 + &s2;

println!("{s3}");
println!("{s2}");
// println!("{s1}"); // 编译错误:s1 已被移动
```

`+` 会取得左操作数 `s1` 的所有权,但只借用 `s2`.拼接完成后 `s1` 不再有效,结果的所有权属于 `s3`.

拼接多个值时,`format!` 通常更清晰,并且不会取得参数所有权:

```rust
let s1 = String::from("tic");
let s2 = String::from("tac");
let s3 = String::from("toe");

let s = format!("{s1}-{s2}-{s3}");

println!("{s}");
println!("{s1}, {s2}, {s3}"); // 原字符串仍然有效
```

/// important | 拼接时先判断所有权需求
只追加少量内容时可以使用 `push_str` 或 `push`;愿意交出左侧 `String` 所有权时可以使用 `+`;需要保留所有参数或组合多个值时优先使用 `format!`.
///

### UTF-8 字节长度

`String::len()` 返回 UTF-8 编码后的字节数,不是人眼看到的字符数量:

```rust
let latin = String::from("Hola");
let cyrillic = String::from("Здравствуйте");

println!("{}", latin.len());    // 4
println!("{}", cyrillic.len()); // 24
```

`"Hola"` 中每个字符占 1 字节,而 `"Здравствуйте"` 中每个西里尔字母占 2 字节.

### 字符边界与字符串切片

字符串切片的索引表示字节位置,起止位置必须同时位于 UTF-8 字符边界:

```rust
let hello = String::from("Здравствуйте");
let first_two = &hello[0..4];

println!("{first_two}"); // Зд
```

前两个西里尔字母共占 4 字节,所以 `0..4` 是有效边界.如果使用 `0..1`,切片会落在一个字符的编码中间并触发 panic.

Rust 不允许使用 `s[0]` 直接索引字符串.一个字节不一定对应一个 Unicode 字符,直接索引无法给出统一且安全的结果.

### 遍历字符与字节

需要按 Unicode 标量值遍历时使用 `chars()`:

```rust
for c in "Здравствуйте".chars() {
    println!("{c}");
}
```

需要查看 UTF-8 原始字节时使用 `bytes()`:

```rust
for b in "Здравствуйте".bytes() {
    println!("{b}");
}
```

/// info | char 不等于用户看到的完整字符
`chars()` 迭代 Unicode 标量值,`bytes()` 迭代 UTF-8 字节.带组合符号的文字可能由多个 `char` 组成,因此二者都不直接等同于用户感知的字形数量.
///

## 常见错误

### Vec 索引越界

```rust
let v = vec![1, 2, 3];
let value = &v[10]; // 运行时 panic
```

索引不确定时改用 `v.get(10)`,并处理返回的 `None`.

### 迭代时同时修改 Vec 结构

```rust
let mut v = vec![1, 2, 3];

for item in &v {
    // v.push(*item); // 编译错误:共享借用期间不能可变借用 v
    println!("{item}");
}
```

`push` 可能重新分配内存,使已有元素引用失效.Rust 因此禁止在共享迭代期间修改向量结构.可以先收集待添加的数据,迭代结束后再统一添加.

### 忘记解引用可变元素

```rust
let mut v = vec![1, 2, 3];

for item in &mut v {
    *item += 1;
}
```

`item` 的类型是 `&mut i32`,必须写成 `*item` 才能修改其指向的值.

### 使用 + 后继续访问左操作数

```rust
let left = String::from("hello");
let right = String::from(" world");
let joined = left + &right;

// println!("{left}"); // 编译错误:left 已被移动
println!("{joined}");
```

如果后续仍需要所有原字符串,应使用 `format!` 或显式克隆确实需要复制的值.

### 在非字符边界切片

```rust
let s = String::from("你好");
// let first = &s[0..1]; // 运行时 panic
let first = &s[0..3];

println!("{first}"); // 你
```

汉字 `你` 的 UTF-8 编码占 3 字节.需要逐字符处理时,应使用 `chars()` 而不是自行猜测字节边界.

/// important | 核心原则
`Vec<T>` 用统一元素类型换取连续、安全的动态存储;`String` 用 UTF-8 保存文本.使用它们时要同时关注借用关系、所有权转移和索引所代表的实际单位.
///
