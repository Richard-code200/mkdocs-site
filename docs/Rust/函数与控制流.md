# 函数与控制流

## 函数(Function)

### 命名规范

```Rust
fn main() {
    println!("Hello, world!");
    another_function();
}

fn another_function() {
    println!("Another function.");
}
```

函数&变量的命名规范: snake case:

- 所有字母都小写;
- 单词之间用"\_"连接;

### 参数

```Rust
fn main() {
    another_function_pro(5);
    print_labeled_measurement(5, 'h');
}

fn another_function_pro(x: i32) {
    println!("The value of x is: {x}");
}
fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}
```

- 必须声明每个参数的类型 `参数名:类型`
- 多个参数需使用 "," 分开

### 语句(Statement) vs 表达式(Expression)

```Rust
fn main() {
  let y = 6;
  //let x =(let y = 6);
  // Rust中不支持通过语句返回值,因此上面这段代码是错误的

  let y = {
    let x = 3;
    x + 1
  };// 该括号内的部分也是一个表达式

  println!("The value of y is: {y}");
}
```

- 语句(Statements): 执行某些操作的指令,不返回值
- 表达式(Expressions): 计算并返回一个结果值

函数体由一系列语句组成,可由表达式结尾

### 函数的返回值

```Rust
fn five() -> i32 {
    5
}

fn plus_one(x: i32) -> i32 {
    x + 1
}

fn main() {// main函数本质也有一个返回值,类型就是()
  let x = five();
  println!("The value of x is: {x}");

  let x = plus_one(5);
  println!("The value of x is: {x}");
  //main函数结尾隐式执行了(),也就是返回了()
  ()
  //添加上也不会报错
}
```

- 使用"->"声明函数返回值的类型
- 返回值:
  - 可以使用 return 返回值
  - 函数体中最后一个表达式的值

## 控制流(Control Flow)

### If表达式

```Rust
fn main() {
    let number = 3;
    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }

    let number = 6;
    if number % 4 == 0 {
        println!("number is divisible by 4");
    } else if number % 3 == 0 {
        println!("number is divisible by 3");
    } else if number % 2 == 0 {
        println!("number is divisible by 2");
    } else {
        println!("number is not divisible by 4, 3, or 2");
    }

    let condition = true;
    let number = if condition { 5 } else { 6 };
    // 此处两个供选择的变量必须是相同类型的,因为Rust编译的时候必须确定变量的类型
    println!("The value of number is: {number}");
}
```

老三样

- if
- else
- else if
