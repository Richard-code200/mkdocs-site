# 泛型与特征

## 泛型(Generics)

泛型允许你编写适用于多种类型的通用代码,避免为每种类型重复编写逻辑.

### 为什么需要泛型

没有泛型时,每种类型都需要单独写一个函数:

```rust
fn max_i32(a: i32, b: i32) -> i32 { ... }
fn max_f64(a: f64, b: f64) -> f64 { ... }
// 逻辑完全相同,只是类型不同
```

使用泛型只需写一次:

```rust
fn max<T>(a: T, b: T) -> T { ... }
// T 是类型占位符,调用时自动替换为具体类型
```

### 泛型结构体

```rust
struct A;              // 单元结构体
struct S(A);           // 元组结构体,包含一个 A
struct SGen<T>(T);     // 泛型元组结构体,T 可以装任何类型
```

`SGen<T>` 是一个"模板",可以生成不同的具体类型:

```rust
let a = SGen(6);       // SGen<i32>
let b = SGen('a');     // SGen<char>
let c = SGen(A);       // SGen<A>
```

### 泛型结构体的实际应用

一个泛型结构体可以根据传入的值自动适配不同类型,无需重复定义:

```rust
struct Point<T> {  // T 是类型占位符,x 和 y 必须是相同类型
    x: T,
    y: T,
}

fn main() {
    let integer = Point { x: 5, y: 10 };   // x, y 都是 i32,编译器推断 T = i32
    let float = Point { x: 1.0, y: 4.0 };  // x, y 都是 f64,编译器推断 T = f64

    // 不需要手动指定类型,编译器从字段值自动推断
    // integer 的完整类型是 Point<i32>
    // float 的完整类型是 Point<f64>
}
```

/// info | 类型推断
Rust 编译器会根据赋值时传入的具体值自动推断泛型参数的类型.大多数情况下不需要手动指定,代码更简洁.只在编译器无法推断时才需要用 turbofish `::<T>` 语法.
///

/// warning | 同一实例中 T 只能是一种类型

```rust
let mixed = Point { x: 5, y: 1.0 }; // 编译错误:expected integer, found floating-point number
```

`Point<T>` 中 `x` 和 `y` 共享同一个 `T`,所以必须是相同类型.如果需要不同类型,可以定义多个泛型参数:`Point<T, U>`.
///

### 多个泛型参数

当结构体的字段需要不同类型时,可以定义多个泛型参数:

```rust
struct Point<T, U> {  // T 和 U 是两个独立的类型参数
    x: T,             // x 的类型是 T
    y: U,             // y 的类型是 U,可以与 T 不同
}

fn main() {
    // 手动指定类型:Point<i32, String>
    let p: Point<i32, String> = Point {
        x: 5,                    // T = i32
        y: "hello".to_string(),  // U = String
    };

    // 也可以让编译器自动推断
    let mixed = Point { x: 5, y: 1.0 };  // T = i32, U = f64
}
```

/// info | 多个泛型参数的命名
多个泛型参数通常用 `T`、`U`、`V` 等字母.参数越多,可读性越差,实际项目中通常不超过 2-3 个.
///

/// info | T 只是约定俗成的名字
`T` 代表 Type(类型),是 Rust 社区的惯例.你可以用任何标识符,但 `T`、`U`、`V` 最常见.
///

### 泛型函数

```rust
fn reg_fn(_s: S) {}          // 普通函数,只接受 S
fn gen_spec_t(_s: SGen<A>) {}     // 泛型被具体化为 A
fn gen_spec_i32(_s: SGen<i32>) {} // 泛型被具体化为 i32
fn generic<T>(_s: SGen<T>) {}     // 泛型函数,接受任意 SGen<T>
```

- `reg_fn`:只能接受 `S` 类型,不灵活
- `gen_spec_t` / `gen_spec_i32`:虽然用了泛型结构体,但函数本身已经固定了具体类型
- `generic<T>`:真正的泛型函数,`T` 在调用时才确定

### 调用泛型函数

```rust
fn main() {
    reg_fn(S(A));                  // 构造 S(A) 传入
    gen_spec_t(SGen(A));           // T 已固定为 A
    gen_spec_i32(SGen(6));         // T 已固定为 i32
    generic::<char>(SGen('a'));    // 手动指定 T = char
    generic(SGen(1.2));            // 编译器自动推断 T = f64
}
```

/// info | turbofish 语法 `::<T>`
`generic::<char>(...)` 中的 `::<char>` 称为 **turbofish**(涡轮鱼)语法,用于手动指定泛型参数的类型.当编译器无法自动推断时使用.大多数情况下编译器能从参数推断类型,可以省略.
///

### 泛型枚举

你已经用过泛型枚举 —— `Option<T>` 就是标准库中最常见的例子:

```rust
enum Option<T> {
    Some(T),
    None,
}

let a: Option<i32> = Some(5);     // T = i32
let b: Option<String> = Some(String::from("hi")); // T = String
```

`Result<T, E>` 也是泛型枚举,用于错误处理:

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

### 泛型方法

可以在 `impl` 块中为泛型结构体定义方法:

```rust
struct Point<T> {
    x: T,
    y: T,
}

impl<T> Point<T> {
    fn x(&self) -> &T {
        &self.x
    }
}

fn main() {
    let p = Point { x: 5, y: 10 };
    println!("x = {}", p.x()); // 5
}
```

也可以为特定类型实现方法:

```rust
impl Point<f64> {
    fn distance_from_origin(&self) -> f64 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}
```

/// warning | impl 块需要声明泛型参数
为泛型结构体写 `impl` 时,必须在 `impl` 后声明类型参数:`impl<T> Point<T>`.忘记写 `<T>` 会编译报错.
///

### 方法自带泛型参数

方法可以声明自己的泛型参数,独立于结构体的泛型参数:

```rust
struct Point<T, U> {
    x: T,
    y: U,
}

impl<T, U> Point<T, U> {
    // V, W 是方法自己的泛型参数,与结构体的 T, U 无关
    fn mixup<V, W>(self, other: Point<V, W>) -> Point<T, W> {
        Point {
            x: self.x,    // 取 self 的 x(类型 T)
            y: other.y,   // 取 other 的 y(类型 W)
        }
    }
}

fn main() {
    let p1 = Point { x: 5, y: 10 };       // Point<i32, i32>
    let p2 = Point { x: "Hello", y: '中' }; // Point<&str, char>

    let p3 = p1.mixup(p2);  // p3.x = 5(i32), p3.y = '中'(char)
    assert_eq!(p3.x, 5);
    assert_eq!(p3.y, '中');
}
```

/// info | 方法的泛型参数 vs 结构体的泛型参数
`impl<T, U>` 声明的是**结构体**的泛型参数,`fn mixup<V, W>` 声明的是**方法**的泛型参数.方法可以同时使用两组参数:`T`、`U` 来自结构体,`V`、`W` 来自方法自身.
///

/// info | self 消耗所有权
`mixup(self, ...)` 中 `self` 没有 `&`,表示方法会**消耗**实例的所有权.调用后 `p1` 不再可用,因为它的字段被移动到了返回值 `p3` 中.
///

### 单态化(Monomorphization)

Rust 在编译时将泛型代码**展开**为具体类型的代码:

```rust
// 你写的泛型代码
fn generic<T>(_s: SGen<T>) {}

// 编译器生成的代码(概念上)
fn generic_i32(_s: SGen<i32>) {}
fn generic_f64(_s: SGen<f64>) {}
fn generic_char(_s: SGen<char>) {}
```

/// important | 泛型零运行时开销
单态化发生在编译期,生成的代码与手写具体类型完全一样.因此 Rust 的泛型**没有运行时性能损失**,这是与 Java/Python 泛型(类型擦除)的核心区别.
///

### 运算符特征约束

Rust 中的运算符(`+`、`-`、`*` 等)都是通过特征实现的.泛型函数中使用运算符时,必须用特征约束告诉编译器 `T` 支持该运算:

```rust
use std::ops::Add;  // use 关键字导入标准库中的 Add 特征

fn sum<T: Add<Output = T>>(a: T, b: T) -> T {
    a + b
}

fn main() {
    assert_eq!(5, sum(2i8, 3i8));       // T = i8
    assert_eq!(50, sum(20, 30));         // T = i32
    assert_eq!(2.46, sum(1.23, 1.23));   // T = f64
    println!("Success!");
}
```

- `T: Add` 表示 T 必须实现 `Add` 特征(支持 `+` 运算)
- `<Output = T>` 表示加法结果的类型也是 T(关联类型)
- `use std::ops::Add` 将 `Add` 特征导入当前作用域

/// info | use 关键字(导入)
`use` 用于将其他模块的内容引入当前作用域,避免每次写完整路径:

```rust
use std::ops::Add;      // 导入 Add 特征
use std::collections::HashMap;  // 导入 HashMap
use std::io::{self, Read};      // 一次导入多个
```

///

/// warning | 不加特征约束会报错

```rust
fn sum<T>(a: T, b: T) -> T {
    a + b  // 编译错误:cannot add T to T
}
```

编译器不知道 `T` 是否支持 `+`,必须显式约束.
///

常用运算符对应的特征:

| 运算符  | 特征         | 所在模块   |
| ------- | ------------ | ---------- |
| `+`     | `Add`        | `std::ops` |
| `-`     | `Sub`        | `std::ops` |
| `*`     | `Mul`        | `std::ops` |
| `/`     | `Div`        | `std::ops` |
| `%`     | `Rem`        | `std::ops` |
| `==`    | `PartialEq`  | `std::cmp` |
| `<` `>` | `PartialOrd` | `std::cmp` |

### 用冒泡排序理解 trait bound

泛型排序需要比较元素.项目中的冒泡排序把参数写成 `T: Ord`,含义是“接受任意类型 `T`,但该类型必须支持全序比较”:

```rust
fn bubble_sort<T: Ord>(arr: &mut [T]) {
    let len = arr.len();
    for i in 0..len {
        let mut swapped = false;
        for j in 0..len - 1 - i {
            if arr[j] > arr[j + 1] {
                arr.swap(j, j + 1);
                swapped = true;
            }
        }
        if !swapped {
            break;
        }
    }
}

let mut numbers = [5, 1, 4, 2];
bubble_sort(&mut numbers);
assert_eq!(numbers, [1, 2, 4, 5]);
```

这里的 `>` 需要比较能力,因此不能只写 `fn bubble_sort<T>`.`Ord` 比 `PartialOrd` 更强,要求任意两个值都有确定顺序,适合整数和字符串等类型;`f32`、`f64` 因为存在 `NaN`,没有实现 `Ord`,不能直接传给这个函数.参数使用 `&mut [T]`,所以数组切片和 `Vec<T>` 切片都能复用同一实现.空切片的 `len` 为 `0`,外层 `0..len` 即 `0..0`,循环体完全不执行,因此不会计算内层范围中的 `len - 1 - i`;单元素切片只执行一次外层循环,此时内层 `0..0` 为空,同样不会索引元素.

## 特征(Trait)

特征(Trait)定义了类型必须实现的行为.类似其他语言中的"接口"(Interface).

### 定义特征

```rust
trait Summary {
    fn summarize(&self) -> String;
}
```

- 使用 `trait` 关键字定义
- 内部只声明方法签名,不提供实现(或提供默认实现)

### 实现特征

```rust
struct Article {
    title: String,
    content: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("{}, by {}", self.title, self.content)
    }
}
```

/// info | 孤儿规则(Orphan Rule)
你可以为**自己的类型**实现**标准库的 trait**,或为**外部类型**实现**自己的 trait**.但不能为外部类型实现外部 trait,这是为了避免冲突.
///

### 默认实现

特征方法可以提供默认实现,实现者可以选择覆盖:

```rust
trait Summary {
    fn summarize(&self) -> String {
        String::from("(Read more...)")
    }
}

struct Tweet {
    username: String,
}

impl Summary for Tweet {} // 不覆盖,使用默认实现
```

### 特征作为参数

特征可以作为函数参数,接受任何实现了该特征的类型:

```rust
fn notify(item: &impl Summary) {
    println!("Breaking news! {}", item.summarize());
}
```

`impl Summary` 是 `T: Summary` 的简写:

```rust
fn notify<T: Summary>(item: &T) {
    println!("Breaking news! {}", item.summarize());
}
```

### 多个特征约束

使用 `+` 要求类型同时实现多个特征:

```rust
fn notify(item: &(impl Summary + Display)) {
    println!("{}", item.summarize());
}

// 等价的完整写法
fn notify<T: Summary + Display>(item: &T) {
    println!("{}", item.summarize());
}
```

### where 子句

当特征约束很多时,用 `where` 让签名更清晰:

```rust
fn some_function<T, U>(t: &T, u: &U) -> i32
where
    T: Display + Clone,
    U: Clone + Debug,
{
    // ...
}
```

### 特征作为返回值

```rust
fn returns_summarizable() -> impl Summary {
    Article {
        title: String::from("Rust"),
        content: String::from("A systems language"),
    }
}
```

/// warning | impl Trait 返回类型的限制
`-> impl Summary` 只能返回**一种**具体类型,不能在不同分支返回不同类型.需要返回不同类型时使用 `Box<dyn Summary>`.
///

### 常用标准库特征

| 特征         | 用途                | derive                  |
| ------------ | ------------------- | ----------------------- |
| `Display`    | `{}` 格式化输出     | 不可 derive,需手动实现  |
| `Debug`      | `{:?}` 调试输出     | `#[derive(Debug)]`      |
| `Clone`      | 显式复制或克隆      | `#[derive(Clone)]`      |
| `Copy`       | 隐式按位复制        | `#[derive(Copy)]`       |
| `PartialEq`  | `==` / `!=` 比较    | `#[derive(PartialEq)]`  |
| `PartialOrd` | `<` / `>` 比较      | `#[derive(PartialOrd)]` |
| `Hash`       | 可作为 HashMap 的键 | `#[derive(Hash)]`       |

`Clone` 的具体语义由类型实现决定,不能一概视为深拷贝.例如 `String::clone` 会复制字符串缓冲区,而 `Rc::clone` 只增加引用计数并共享同一份数据.

/// important | 泛型 + 特征 = Rust 核心范式
泛型提供**类型灵活性**,特征提供**行为约束**.两者结合让你写出"适用于任何满足条件的类型"的代码,同时保持编译期类型安全和零运行时开销.
///
