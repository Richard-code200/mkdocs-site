# 切片(Slice)

切片是一种**不获取所有权**的引用类型,它引用集合中一段**连续元素序列**,而非整个集合.

## 为什么需要切片

考虑一个查找单词结尾索引的问题:

```rust
fn main() {
    let mut s = String::from("hello world");
    let word = first_word(&s);
    s.clear(); // s 被清空,word 的值(索引)仍有意义吗?
}

fn first_word(s: &String) -> usize {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }
    s.len()
}
```

`word` 作为 `usize` 与 `s` 的状态**没有绑定关系** -- `s.clear()` 之后,索引 `5` 已毫无意义,但编译器不会报错.切片解决了这个问题.

/// info | 切片的核心价值
切片将值的使用与原始数据**生命周期绑定**,编译器能在数据被修改或释放时发现悬垂引用问题.
///

## 切片是"胖指针"

切片是一种特殊的引用 -- **胖指针**(Fat Pointer),额外携带了元数据:

```
&str 内存布局:
+--------+--------+
|  指针   |  长度   |
| (usize) | (usize) |
+--------+--------+
    |      6
    v
+---+---+---+---+---+---+
| h | e | l | l | o |   |
+---+---+---+---+---+---+
   堆/String 内部数据
```

- 普通引用 `&T`: 8 字节(只存储指针)
- 切片 `&str` / `&[T]`: 16 字节(指针 + 长度)

/// warning | 小知识
Rust 的胖指针实现让切片始终携带长度信息,因此**无需像 C 那样依赖 '\0' 终止符**,也永远不会发生缓冲区溢出.
///

## 字符串切片(String Slices)

### 基本语法

```rust
let s = String::from("hello world");

let hello: &str = &s[0..5];  // "hello"
let world: &str = &s[6..11]; // "world"
let s2: &String = &s;        // 对整个 String 的引用,不是切片
```

区间是 `[起始索引 .. 结束索引]`,**左闭右开**:包含起始索引,不包含结束索引.

/// important | UTF-8 边界约束
字符串切片范围必须落在有效的 UTF-8 字符边界上.如果试图在多字节字符的中间位置创建切片,程序会在**运行时 panic**.
///

### 改造后的 first_word

```rust
fn main() {
    let mut s = String::from("hello world");
    let word = first_word(&s);
    // s.clear(); // 编译错误!word 持有 s 的不可变引用
}

fn first_word(s: &String) -> &str {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[..i];
        }
    }
    &s[..]
}
```

现在 `word` 的类型是 `&str`(切片引用),编译器会阻止对 `s` 的任何修改 -- 因为 `word` 借用了 `s`.

## 范围语法(Range)

```rust
let s = String::from("hello world");

let slice = &s[0..2];   // "he"
let slice = &s[..2];    // 同上,从 0 开始可省略

let len = s.len();

let slice = &s[3..len]; // "lo world"
let slice = &s[3..];    // 同上,到末尾可省略

let slice = &s[0..len]; // "hello world"
let slice = &s[..];     // 同上,整个字符串
```

区间语法总结:

| 写法       | 等同          | 含义     |
| ---------- | ------------- | -------- |
| `&s[a..b]` | 索引 a 到 b-1 | 指定起止 |
| `&s[..b]`  | 索引 0 到 b-1 | 从开头   |
| `&s[a..]`  | 索引 a 到末尾 | 到末尾   |
| `&s[..]`   | 整个          | 所有元素 |

## 字符串字面量就是切片

```rust
let s = "Hello, world!"; // s 的类型是 &str
```

字符串字面量 `"Hello, world!"` 的类型是 `&str` -- 它指向二进制文件中一段只读内存的切片位置.

- 因为 `&str` 是不可变引用,所以字符串字面量不可变
- 字面量的数据在编译时嵌入到可执行文件中

```rust
fn first_word(s: &str) -> &str { // 使用 &str 而非 &String
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[..i];
        }
    }
    &s[..]
}
```

/// important | 总是用 &str 作为字符串参数
`&str` 可以接受 `&String`(通过 Deref 强制转换) 和 `&str` 两种实参,而 `&String` 只能接受 `&String`.编写函数时优先用 `&str`,接口更通用.
///

`Deref` 强制转换让 `&String` 能自动变身 `&str`:

```rust
let s = String::from("hello");
let word = first_word(&s);   // &String 自动转换为 &str

let lit = "hello world";     // 字面量本身就是 &str
let word2 = first_word(lit); // 直接传入
```

## 数组切片 `&[T]`

切片不限于字符串,所有连续内存的集合类型都支持:

```rust
let a = [1, 2, 3, 4, 5];
let slice: &[i32] = &a[1..3]; // 类型 &[i32],指向 [2, 3]
assert_eq!(slice, &[2, 3]);
```

其他支持切片的类型:

- `Vec<T>` -- 动态数组
- `&[T]` -- 数组切片本身也可以再切片
- `[T; N]` -- 定长数组

```rust
let v = vec![10, 20, 30, 40, 50];
let slice = &v[2..4]; // &[i32],引用 Vec 的一部分
assert_eq!(slice, &[30, 40]);
```

/// info | 切片的性能
切片**不会拷贝底层数据**,只创建一个胖指针(16 字节).无论原始数据多大,切片创建的代价都是恒定的 O(1).
///
