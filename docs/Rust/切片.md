# 切片(Slice)

切片是一种**不获取所有权**的引用类型,它引用集合中一段**连续元素序列**,而非整个集合.

## 为什么需要切片

考虑一个查找第一个单词的问题.项目中的函数返回输入开头到第一个 ASCII 空格之前的切片;空输入返回 `None`:

```rust
fn main() {
    let s = String::from("hello world");

    match first_word(&s) {
        Some(word) => println!("第一个单词: {word}"),
        None => println!("输入为空"),
    }
}
```

如果函数只返回 `usize`,索引与 `s` 的状态就**没有绑定关系**:`s.clear()` 后旧索引已失去意义,编译器却无法发现.这里返回的 `Option<&str>` 不仅用 `None` 表示空输入,还让 `Some` 中的切片与原字符串的生命周期绑定.完整函数见下文“改造后的 first_word”.

/// info | 切片的核心价值
切片将值的使用与原始数据**生命周期绑定**,编译器能在数据被修改或释放时发现悬垂引用问题.
///

## 切片是"胖指针"

切片是一种特殊的引用 -- **胖指针**(Fat Pointer),额外携带了元数据:

```
&str 内存布局:
+--------+--------+
|  指针   |  长度   |
| (usize) | (usize) |
+--------+--------+
    |      6
    v
+---+---+---+---+---+---+
| h | e | l | l | o |   |
+---+---+---+---+---+---+
   堆/String 内部数据
```

- 普通引用 `&T` 是瘦指针,通常占一个机器字
- 切片 `&str` / `&[T]` 是胖指针,通常占两个机器字(数据指针 + 长度)

具体字节数随目标平台的指针宽度而变化.

/// warning | 小知识
切片携带长度信息,无需像 C 那样依赖 `\0` 终止符.在安全 Rust 中,切片访问受边界和 UTF-8 字符边界检查,非法访问会编译失败或 panic,而不是造成未定义内存访问;`unsafe` 和 FFI 不在此保证范围内.
///

## 字符串切片(String Slices)

### 基本语法

```rust
let s = String::from("hello world");

let hello: &str = &s[0..5];  // "hello"
let world: &str = &s[6..11]; // "world"
let s2: &String = &s;        // 对整个 String 的引用,不是切片
```

区间是 `[起始索引 .. 结束索引]`,**左闭右开**:包含起始索引,不包含结束索引.

/// important | UTF-8 边界约束
字符串切片范围必须落在有效的 UTF-8 字符边界上.如果试图在多字节字符的中间位置创建切片,程序会在**运行时 panic**.
///

### 改造后的 first_word

```rust
fn main() {
    let mut s = String::from("hello world");
    let word = first_word(&s);
    // s.clear(); // 编译错误:下方仍要使用借用 s 的 word
    match word {
        Some(word) => println!("第一个单词: {word}"),
        None => println!("输入为空"),
    }
}

fn first_word(s: &str) -> Option<&str> {
    if s.is_empty() {
        return None;
    }

    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return Some(&s[..i]);
        }
    }
    Some(s)
}
```

现在 `word` 的类型是 `Option<&str>`.当其中包含切片且后续仍会使用时,编译器会阻止修改 `s`,因为该切片借用了 `s`.

## 范围语法(Range)

```rust
let s = String::from("hello world");

let slice = &s[0..2];   // "he"
let slice = &s[..2];    // 同上,从 0 开始可省略

let len = s.len();

let slice = &s[3..len]; // "lo world"
let slice = &s[3..];    // 同上,到末尾可省略

let slice = &s[0..len]; // "hello world"
let slice = &s[..];     // 同上,整个字符串
```

区间语法总结:

| 写法       | 等同          | 含义     |
| ---------- | ------------- | -------- |
| `&s[a..b]` | 索引 a 到 b-1 | 指定起止 |
| `&s[..b]`  | 索引 0 到 b-1 | 从开头   |
| `&s[a..]`  | 索引 a 到末尾 | 到末尾   |
| `&s[..]`   | 整个          | 所有元素 |

## 字符串字面量就是切片

```rust
let s = "Hello, world!"; // s 的类型是 &str
```

字符串字面量 `"Hello, world!"` 的类型是 `&str` -- 它指向二进制文件中一段只读内存的切片位置.

- 因为 `&str` 是不可变引用,所以字符串字面量不可变
- 字面量的数据在编译时嵌入到可执行文件中

上文的权威实现使用 `&str` 参数,因此既能接受 `&String`,也能接受字符串字面量.它只把字节 `b' '` 视为分隔符,不会把制表符、换行或其他 Unicode 空白当作分隔符.非空输入若以 ASCII 空格开头,结果是 `Some("")`.

/// important | 总是用 &str 作为字符串参数
`&str` 可以接受 `&String`(通过 Deref 强制转换) 和 `&str` 两种实参,而 `&String` 只能接受 `&String`.编写函数时优先用 `&str`,接口更通用.
///

`Deref` 强制转换让 `&String` 能自动变身 `&str`:

```rust
let s = String::from("hello");
match first_word(&s) {       // &String 自动转换为 &str
    Some(word) => println!("{word}"),
    None => println!("输入为空"),
}

let lit = "hello world";     // 字面量本身就是 &str
if let Some(word) = first_word(lit) { // 直接传入并处理 Option
    println!("{word}");
}
```

## ASCII 空格状态机与边界

项目中的 `nth_word` 使用 `InWord` / `OutWord` 两个状态扫描字节,连续的 ASCII 空格不会产生空单词,索引从 `0` 开始:

```rust
#[derive(PartialEq)]
enum State {
    InWord,
    OutWord,
}

fn nth_word(s: &str, n: usize) -> Option<&str> {
    let bytes = s.as_bytes();
    let mut state = State::OutWord;
    let mut word_count = 0;
    let mut start = 0;

    for (i, &byte) in bytes.iter().enumerate() {
        match (&state, byte) {
            (State::OutWord, b' ') => {}
            (State::OutWord, _) => {
                if word_count == n {
                    start = i;
                }
                state = State::InWord;
            }
            (State::InWord, b' ') => {
                if word_count == n {
                    return Some(&s[start..i]);
                }
                word_count += 1;
                state = State::OutWord;
            }
            (State::InWord, _) => {}
        }
    }

    if state == State::InWord && word_count == n {
        Some(&s[start..])
    } else {
        None
    }
}

assert_eq!(nth_word("   Hello    World   ", 0), Some("Hello"));
assert_eq!(nth_word("   Hello    World   ", 1), Some("World"));
assert_eq!(nth_word("   Hello    World   ", 2), None);
```

/// warning | `b' '` 只识别 ASCII 空格
字节状态机若只判断 `b' '`,不会把制表符、换行或全角空格视为分隔符.它仍能安全返回 UTF-8 切片,因为起止位置来自完整扫描到的 ASCII 空格边界,但“单词”的定义很窄.需要处理 Unicode 空白时,优先使用 `str::split_whitespace()`;若业务规则更复杂,应先明确分词规范.
///

## 数组切片 `&[T]`

切片不限于字符串,所有连续内存的集合类型都支持:

```rust
let a = [1, 2, 3, 4, 5];
let slice: &[i32] = &a[1..3]; // 类型 &[i32],指向 [2, 3]
assert_eq!(slice, &[2, 3]);
```

其他支持切片的类型:

- `Vec<T>` -- 动态数组
- `&[T]` -- 数组切片本身也可以再切片
- `[T; N]` -- 定长数组

```rust
let v = vec![10, 20, 30, 40, 50];
let slice = &v[2..4]; // &[i32],引用 Vec 的一部分
assert_eq!(slice, &[30, 40]);
```

/// info | 切片的性能
切片**不会拷贝底层数据**,只创建通常由数据指针和长度组成的胖指针;具体大小随目标平台而变化.无论原始数据多大,切片创建的代价都是恒定的 O(1).
///
