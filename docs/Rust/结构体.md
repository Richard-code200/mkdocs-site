# 结构体(Struct)

## 定义与使用

### 定义结构体

```rust
struct User {
    active: bool,
    username: String,
    email: String,
    sign_in_count: u64,
}
```

- 使用 `struct` 关键字定义
- 结构体名采用 **PascalCase** 命名法(各单词首字母大写)
- 内部为字段及其类型

/// info | 结构体的内存布局
结构体实例根据字段类型分配内存:栈上类型(如 `bool`、`u64`)直接存储,堆上类型(如 `String`)存储指向堆内存的指针.
///

### 创建实例

```rust
fn main() {
    let mut user1 = User {
        active: true,
        username: String::from("ERRORichard"),
        email: String::from("ERRORichard@gmail.com"),
        sign_in_count: 1,
    };

    user1.email = String::from("ERRORichard@protonmail.com");
}
```

- 创建实例时字段顺序**不必**与定义顺序一致
- 使用 `实例.字段` 语法访问或修改字段(实例需要声明为 `mut`)

### 字段初始化简写

```rust
fn build_user(email: String, username: String) -> User {
    User {
        active: true,
        username,
        email,
        sign_in_count: 1,
    }
}
```

当参数名与字段名相同时,可以只写字段名,省略 `字段: 参数` 的重复写法.

/// info | 字段初始化简写
类似 JavaScript 的对象属性简写,当变量名和字段名一致时,Rust 允许省略 `: 变量名` 部分,代码更简洁.
///

### 结构体更新语法

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: String::from("another@example.com"),
    sign_in_count: user1.sign_in_count,
};

let user2 = User {
    email: String::from("another@example.com"),
    ..user1
};
```

使用 `..其他实例` 语法,表示未显式指定的字段与另一个实例相同.

/// warning | 更新语法的移动语义
`..user1` 会将 `user1` 中未显式赋值的字段**移动**到 `user2`.如果字段类型没有实现 `Copy`,则 `user1` 中对应的字段将不再有效.
///

## 元组结构体(Tuple Struct)

```rust
struct Color(i32, i32, i32);
struct Point(i32, i32, i32);

fn main() {
    let black = Color(0, 0, 0);
    let origin = Point(0, 0, 0);
}
```

- 没有字段名,只有字段类型
- 不同名的元组结构体是**不同类型**,即使字段完全相同
- 通过 `.0`、`.1` 等索引访问字段

/// info | 何时使用元组结构体
当结构体的字段不需要命名,但整体需要一个独立类型时使用.例如 `Color(255, 0, 0)` 比 `(255, 0, 0)` 语义更清晰,且编译器能防止类型混淆.
///

## 单元结构体(Unit-like Struct)

```rust
struct AlwaysEqual;

fn main() {
    let subject = AlwaysEqual;
}
```

- 没有任何字段
- 类似于元组 `()`(单元类型)
- 常用于实现 trait 而不需要存储数据

## 方法(Method)

### 定义方法

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}
```

- 使用 `impl` 块为结构体定义方法
- 第一个参数为 `&self`(不可变借用)或 `&mut self`(可变借用)
- `#[derive(Debug)]` 让结构体可以用 `{:?}` 或 `{:#?}` 格式化输出

/// important | 方法 vs 函数
方法定义在 `impl` 块中,第一个参数是 `self`(或其引用);函数是独立的 `fn`,不绑定到特定类型.方法通过 `实例.方法名()` 调用,函数通过 `函数名(参数)` 调用.
///

### 调用方法

```rust
fn main() {
    let rect1 = Rectangle {
        width: 30,
        height: 50,
    };

    println!(
        "The area of the rectangle is {} square pixels.",
        rect1.area()
    );
    println!("rect1 is {:#?}", rect1);
}
```

### 调试工具

```rust
let scale = 2;
let rect1 = Rectangle {
    width: dbg!(30 * scale),
    height: 50,
};
dbg!(&rect1);
```

- `dbg!(expr)`:打印表达式的值和位置,并**返回**该值(不影响表达式结果)
- `println!("{:#?}", value)`:以易读的格式打印实现了 `Debug` trait 的值

/// info | dbg! vs println!
`dbg!` 会打印文件名、行号、表达式和值,适合调试;`println!` 只输出格式化字符串,适合正式输出.`dbg!` 返回传入的值,可以嵌入表达式中使用.
///

### self 的不同形式

方法的第一个参数决定了方法对实例的访问方式:

```rust
#[derive(Debug)]
struct Counter {
    value: i32,
}

impl Counter {
    fn get(&self) -> i32 {
        self.value
    }

    fn increment(&mut self) {
        self.value += 1;
    }

    fn reset(mut self) -> Counter {
        self.value = 0;
        self
    }

    fn into_string(self) -> String {
        format!("Counter({})", self.value)
    }
}
```

| 形式        | 含义                     | 调用后实例状态 |
| ----------- | ------------------------ | -------------- |
| `&self`     | 不可变借用,只读访问      | 仍然可用       |
| `&mut self` | 可变借用,可修改字段      | 仍然可用       |
| `self`      | 获取所有权(消耗实例)     | 不再可用       |
| `mut self`  | 获取所有权且允许内部修改 | 不再可用       |

/// important | 何时使用 self(获取所有权)
当方法需要**消耗**实例(如转换为其他类型、析构)时使用 `self`.调用后原变量不再可用,因为所有权已转移给方法.常见于 `into_*` 系列方法.
///

```rust
fn main() {
    let mut c = Counter { value: 0 };

    println!("{}", c.get());     // &self: 只读
    c.increment();               // &mut self: 修改
    println!("{}", c.get());     // 1

    let c = c.reset();           // mut self: 消耗后返回新实例
    let s = c.into_string();     // self: 消耗, c 不再可用
    println!("{s}");             // "Counter(0)"
}
```

## 关联函数(Associated Functions)

`impl` 块中**不以 `self` 为参数**的函数称为关联函数,通过 `类型名::函数名` 调用:

```rust
impl Rectangle {
    fn new(width: u32, height: u32) -> Rectangle {
        Rectangle { width, height }
    }

    fn square(size: u32) -> Rectangle {
        Rectangle {
            width: size,
            height: size,
        }
    }
}

fn main() {
    let rect = Rectangle::new(30, 50);
    let sq = Rectangle::square(10);
}
```

- 关联函数不是方法,不绑定到实例
- 常用于**构造函数**,如标准库中的 `String::from`、`Vec::new`
- 使用 `::` 语法调用,而非 `.` 语法

/// info | Rust 没有真正的构造函数
Rust 没有像 Java/C++ 那样的特殊构造语法.关联函数 `new` 只是一种约定俗成的命名,编译器不会对其做特殊处理.你可以定义任意名称的关联函数作为构造入口.
///

## 多个 impl 块

一个结构体可以有多个 `impl` 块,所有块中定义的方法和关联函数效果相同:

```rust
impl Rectangle {
    fn new(width: u32, height: u32) -> Rectangle {
        Rectangle { width, height }
    }
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

impl Rectangle {
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}
```

/// info | 何时拆分 impl 块
功能简单时放在一个 `impl` 块即可.当方法较多时,可以按职责拆分多个 `impl` 块提升可读性.此外,泛型结构体的不同 trait 实现也必须分写在不同的 `impl` 块中.
///

## 常用 derive 宏

通过 `#[derive(...)]` 属性可以自动为结构体实现标准库提供的 trait:

```rust
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
struct Point {
    x: f64,
    y: f64,
}
```

| derive 宏     | 提供的能力                               |
| ------------- | ---------------------------------------- |
| `Debug`       | 用 `{:?}` / `{:#?}` 格式化打印          |
| `Clone`       | 调用 `.clone()` 进行深拷贝               |
| `Copy`        | 赋值时隐式按位复制(要求所有字段都是 Copy) |
| `PartialEq`   | 使用 `==` / `!=` 比较                    |
| `Eq`          | 标记等价关系满足自反性(需先 derive PartialEq) |
| `PartialOrd`  | 使用 `<` / `>` / `<=` / `>=` 比较       |
| `Ord`         | 全序比较(需先 derive Eq, PartialOrd)     |
| `Hash`        | 可作为 `HashMap` / `HashSet` 的键        |
| `Default`     | 提供 `Default::default()` 创建默认值     |

/// warning | derive 的前提
derive 宏要求结构体的**所有字段**都实现了对应的 trait.例如 `#[derive(Clone)]` 要求每个字段都实现了 `Clone`,否则编译报错.
///

```rust
#[derive(Debug, PartialEq)]
struct Point {
    x: f64,
    y: f64,
}

fn main() {
    let p1 = Point { x: 1.0, y: 2.0 };
    let p2 = Point { x: 1.0, y: 2.0 };

    println!("{p1:?}");          // Point { x: 1.0, y: 2.0 }
    println!("{}", p1 == p2);    // true(PartialEq)
}
```

## 实现 Display trait

`Debug` 用于调试输出,而 `Display` 用于面向用户的自定义格式化:

```rust
use std::fmt;

struct Rectangle {
    width: u32,
    height: u32,
}

impl fmt::Display for Rectangle {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}x{} rectangle", self.width, self.height)
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };
    println!("{rect}");    // "30x50 rectangle"
    println!("{rect:#?}"); // 编译错误:未 derive Debug
}
```

- 需要手动 `impl fmt::Display for 类型名`
- `write!` 宏将格式化内容写入 `Formatter`
- 实现后可用 `{}` 占位符打印

/// important | Display vs Debug
`Debug` 可以通过 `#[derive(Debug)]` 自动生成,适合开发调试;`Display` 必须手动实现,用于控制面向用户的输出格式.标准库的 `String`、`i32` 等类型同时实现了两者.
///

## 结构体与所有权

### 结构体的 Drop

当结构体实例离开作用域时,Rust 会自动调用 `drop`,逐字段释放资源:

```rust
struct User {
    username: String,
    email: String,
}

fn main() {
    let user = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
    };
} // user 离开作用域:
  // 1. user.email (String) 的 drop 被调用,释放堆内存
  // 2. user.username (String) 的 drop 被调用,释放堆内存
  // 3. user 本身(栈上数据)被释放
```

/// info | 字段按声明的逆序 drop
Rust 按照字段在结构体中**声明的逆序**调用 drop.这保证了后声明的字段先释放,避免依赖关系导致的问题.
///

### 自定义 Drop

可以通过实现 `Drop` trait 自定义释放行为:

```rust
struct FileHandle {
    name: String,
}

impl Drop for FileHandle {
    fn drop(&mut self) {
        println!("Closing file: {}", self.name);
    }
}

fn main() {
    let f = FileHandle { name: String::from("data.txt") };
    println!("Using file...");
} // "Closing file: data.txt" -- drop 自动调用
```

/// warning | 不能手动调用 drop
Rust 禁止手动调用 `drop` 方法(防止双重释放).如需提前释放,使用 `std::mem::drop(value)` 函数,它会获取所有权并立即释放.
///

### 手动提前释放

```rust
let s = String::from("hello");
drop(s);            // 提前释放
// println!("{s}"); // 编译错误:s 已被释放
```
