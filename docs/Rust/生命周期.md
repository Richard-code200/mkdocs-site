# 生命周期

生命周期(Lifetime)是 Rust 中引用的有效作用域.编译器通过生命周期确保**引用始终指向有效的数据**,防止悬垂引用.

## 为什么需要生命周期

```rust
let r;
{
    let x = 5;
    r = &x;
}
println!("r: {r}"); // 编译错误:`x` does not live long enough
```

`x` 在内部作用域结束时被释放,但 `r` 仍然引用 `x` 的内存.生命周期注解让编译器在**编译时**就能发现这类问题.

## 生命周期注解语法

生命周期参数以 `'` 开头,通常用小写字母命名:

```rust
&i32        // 普通引用
&'a i32     // 带生命周期注解的引用
&'a mut i32 // 带生命周期注解的可变引用
```

`'a` 读作"生命周期 a",表示这个引用的有效期至少和 `'a` 一样长.

## 函数中的生命周期

当函数返回引用时,编译器需要知道返回的引用和哪个参数关联:

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}
```

`'a` 的含义:返回的引用的生命周期等于 `x` 和 `y` 中**较短**的那个.

```rust
fn main() {
    let string1 = String::from("long string");
    let result;
    {
        let string2 = String::from("xyz");
        result = longest(string1.as_str(), string2.as_str());
        println!("较长的字符串是 {result}");
    }
}
```

/// info | 生命周期不改变实际作用域
生命周期注解只是**描述**引用之间的关系,不会改变任何引用的实际存活时间.它帮助编译器进行静态分析,而非运行时行为.
///

## 结构体中的生命周期

当结构体包含引用时,必须标注生命周期:

```rust
struct Person<'a> {
    name: &'a str,
    age: u8,
}

fn main() {
    let name = "Peter";
    let age = 27;
    let peter = Person { name, age };
    println!("{:#?}", peter);
}
```

`'a` 表示 `Person` 实例中 `name` 引用的数据必须活得和 `Person` 一样长.

/// warning | 结构体不能持有悬垂引用

```rust
struct Important<'a> {
    part: &'a str,
}

fn main() {
    let i;
    {
        let s = String::from("hello");
        i = Important { part: &s };
    }
    // 编译错误:`s` does not live long enough
    // i 的 part 引用了已释放的 s
}
```

///

## 生命周期省略规则

编译器有三条自动推断规则,满足时不需要手动标注:

### 规则一:每个引用参数获得独立的生命周期

```rust
fn foo<'a, 'b>(x: &'a str, y: &'b str)
// 编译器自动为每个引用参数分配不同的生命周期
```

### 规则二:只有一个输入生命周期时,它被赋给所有输出引用

```rust
fn first_word(s: &str) -> Option<&str>
// 等价于:
fn first_word<'a>(s: &'a str) -> Option<&'a str>
```

这就是为什么 `first_word` 不需要手动标注 —— 只有一个引用参数,编译器会把 `Option` 中输出引用的生命周期推断为与输入引用相同.完整契约与实现见[切片笔记](切片.md).

### 规则三:有 `&self` 或 `&mut self` 时,self 的生命周期被赋给所有输出引用

```rust
impl<'a> Important<'a> {
    fn level(&self) -> i32 { 3 }

    fn announce_and_return(&self, announcement: &str) -> &str {
        println!("Attention: {announcement}");
        self.part
    }
}
```

`announce_and_return` 有两个引用参数(`&self` 和 `&str`),根据规则三,返回值的生命周期等于 `self` 的生命周期.

/// info | 省略规则的实际效果
大多数情况下你不需要手动标注生命周期,因为编译器会自动应用这三条规则.只有在编译器无法推断时(如函数有多个引用参数且返回引用),才需要手动标注.
///

## 'static 生命周期

`'static` 表示引用在整个程序运行期间都有效:

```rust
let s: &'static str = "I have a static lifetime.";
```

字符串字面量的类型是 `&'static str`,因为它们存储在程序的二进制文件中,永远不会被释放.

/// warning | 不要滥用 'static
`'static` 意味着"永远有效",大多数引用不需要这么长的生命周期.如果编译器建议你加 `'static`,通常意味着代码有更深层次的问题,应该先检查引用关系是否合理.
///

## 生命周期约束

可以指定生命周期之间的关系:

```rust
fn longest<'a: 'b, 'b>(x: &'a str, y: &'b str) -> &'a str {
    // 'a: 'b 表示 'a 至少和 'b 一样长
    if x.len() > y.len() { x } else { y }
}
```

结构体中也可以加约束:

```rust
struct Pair<'a, 'b: 'a> {
    first: &'a str,
    second: &'b str,
}
```

## 生命周期与泛型结合

```rust
use std::fmt::Display;

fn longest_with_an_announcement<'a, T>(
    x: &'a str,
    y: &'a str,
    ann: T,
) -> &'a str
where
    T: Display,
{
    println!("Announcement! {ann}");
    if x.len() > y.len() { x } else { y }
}
```

`'a` 是生命周期参数,`T` 是类型参数,它们可以共存.生命周期参数写在类型参数前面.

/// important | 生命周期核心要义
生命周期是 Rust 借用检查器的核心机制.它不改变程序行为,只帮助编译器验证引用的有效性.大多数时候编译器能自动推断,你只需在必要时手动标注.
///
