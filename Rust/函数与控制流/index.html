函数与控制流

函数(Function)

fn 是 function(函数)的缩写.

命名规范

fn main() {
    println!("Hello, world!");
    another_function();
}

fn another_function() {
    println!("Another function.");
}

函数和变量的命名规范遵循 snake_case 风格:

  • 所有字母都小写
  • 单词之间用 _ 连接
为什么是 snake_case

Rust 官方推荐 snake_case 命名风格,编译器在非 snake_case 命名时会发出警告. 这与 Java 的 camelCase 和 Python 的 PEP8 类似,是 Rust 社区约定俗成的规范.

参数

fn main() {
    another_function_pro(5);
    print_labeled_measurement(5, 'h');
}

fn another_function_pro(x: i32) {
    println!("The value of x is: {x}");
}
fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}
  • 必须声明每个参数的类型,格式为 参数名: 类型
  • 多个参数用 , 分隔
参数类型不可省略

与 JavaScript/Python 不同,Rust 函数参数必须显式标注类型.编译器不会根据调用处的传入值推断参数类型,这是静态类型系统的严格要求.

语句(Statement) vs 表达式(Expression)

fn main() {
    let y = 6;

    let y = {
        let x = 3;
        x + 1
    };

    println!("The value of y is: {y}");
}
  • 语句(Statement):执行某些操作的指令,不返回值
  • 表达式(Expression):计算并返回一个结果值
语句 vs 表达式

Rust 中 let y = 6 是语句,不返回值,因此不能写 let x = (let y = 6);. 而 { let x = 3; x + 1 } 是一个代码块表达式,最后一个表达式 x + 1 的值就是整个块的值. 注意 x + 1 后面不能加分号,加分号会使其变成语句,返回 ().

函数体由一系列语句组成,可由表达式结尾作为返回值.

函数的返回值

fn five() -> i32 {
    5
}

fn plus_one(x: i32) -> i32 {
    x + 1
}

fn main() {
    let x = five();
    println!("The value of x is: {x}");

    let x = plus_one(5);
    println!("The value of x is: {x}");
}
  • 使用 -> 声明函数返回值的类型
  • 返回值可以是以下两种方式之一:
  • 使用 return 关键字显式返回
  • 函数体中最后一个表达式的值(不加分号)
隐式返回与单元类型 ()

Rust 函数的隐式返回值是最后一个表达式,不要加分号,否则返回值类型会变成单元类型 ().main 函数默认返回 (),也可以显式写 () 作为最后一个表达式.

控制流(Control Flow)

If表达式

fn main() {
    let number = 3;
    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }

    let number = 6;
    if number % 4 == 0 {
        println!("number is divisible by 4");
    } else if number % 3 == 0 {
        println!("number is divisible by 3");
    } else if number % 2 == 0 {
        println!("number is divisible by 2");
    } else {
        println!("number is not divisible by 4, 3, or 2");
    }

    let condition = true;
    let number = if condition { 5 } else { 6 };
    println!("The value of number is: {number}");
}

老三样:

  • if
  • else if
  • else
if 表达式的分支类型必须一致

当 if 用作表达式赋值时(如 let number = if condition { 5 } else { 6 };),每个分支的返回值类型必须相同. 因为 Rust 在编译时需要确定变量的具体类型,不能运行时动态改变.

循环(loop,while,for)

loop

fn main() {
    loop {
        println!("again!");
    }
}

fn main() {
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2;
        }
    };
    println!("The result is {result}");
}

fn main() {
    let mut count = 0;
    'counting_up: loop {
        println!("count = {count}");
        let mut remaining = 10;

        loop {
            println!("remaining = {remaining}");
            if remaining == 9 {
                break;
            }
            if count == 2 {
                break 'counting_up;
            }
            remaining -= 1;
        }
        count += 1;
    }
    println!("End count = {count}");
}
  • break:停止循环
  • continue:跳过本次迭代的剩余代码,直接进入下一轮循环
  • 从 loop 返回值:break 表达式,直接返回一个值
fn main() {
    for i in 0..10 {
        if i % 2 == 0 {
            continue; // 跳过偶数
        }
        println!("{i}"); // 只打印奇数: 1, 3, 5, 7, 9
    }
}
break 和 continue 适用于所有循环

break 和 continue 不仅适用于 loop,也适用于 while 和 for 循环.

loop 标签(Label)

在嵌套循环中,可以为 loop 加上 '标签名: 前缀,然后在 break 或 continue 后指定标签名,精确控制跳出或继续哪一层循环. 不带标签的 break 只会跳出最内层循环.

fn main() {
    let mut count = 0;
    'outer: loop {
        'inner: loop {
            if count >= 20 {
                break 'inner;  // 跳出 inner 循环
            }
            count += 2;
        }
        count += 5;
        if count >= 30 {
            break 'outer;      // 跳出 outer 循环
        }
        continue 'outer;       // 跳回 outer 循环开头
    }
    assert!(count == 30);
}
  • break '标签:跳出指定标签的循环
  • continue '标签:跳到指定标签循环的下一次迭代

while

fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{number}!");
        number -= 1;
    }
    println!("LIFTOFF!!!");
}

通过判断 while 后面的条件是否为 true 来反复执行循环体.

for

fn main() {
    let a = [10, 20, 30, 40, 50];
    for element in a {
        println!("the value is: {element}");
    }
}

fn main() {
    for number in (1..4).rev() {  // rev = reverse(反转)
        println!("{number}!");
    }
    println!("LIFTOFF!!!");
}
  • for 元素 in 集合 { ... }:遍历集合中的每个元素
  • Range:用于让 for 循环执行特定次数
fn main() {
    for i in 0..5 {
        println!("{i}");  // 0, 1, 2, 3, 4（不含 5）
    }
    for i in 0..=5 {
        println!("{i}");  // 0, 1, 2, 3, 4, 5（含 5）
    }
}
写法 含义
a..b 半开区间 [a,b)
a..=b 闭区间 [a,b]
未使用的循环变量

当循环变量未被使用时,用 _ 代替,避免编译器警告:

for _ in 0..10 {
    println!("hello");
}
for 循环的安全性

相比 while 配合索引手动遍历数组,for 循环无需手动管理索引变量,编译器会在编译时保证不会越界,更加安全简洁. Rust 推荐优先使用 for 进行迭代.
