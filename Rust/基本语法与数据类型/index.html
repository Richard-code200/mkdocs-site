基本语法与数据类型

基本语法

变量 & 可变性(Variables & Mutability)

fn main() {  // fn = function(函数)
    let mut x = 5;  // mut = mutable(可变的)
    println!("The value of x is: {x}");

    x = 6;
    println!("The value of x is: {x}");
}
变量默认不可变

在 Rust 中,变量默认是不可变的(immutable),这是 Rust 保障内存安全的重要设计理念之一.使用 mut 关键字可以声明可变变量.

常量(Constants)

声明常量(const = constant,常量)

fn main() {
    const SPECIAL_NUMBER: i32 = 3;
}

const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;

使用 const 声明,规则如下:

  • 不可以使用 mut
  • 必须标注类型
  • 可在任意作用域声明
  • 仅可以使用常量表达式赋值
const 与 let 的区别

const 是编译期常量,值在编译时确定;let 声明的是运行时变量.const 必须显式标注类型,且不可使用 mut.

变量遮蔽(Shadowing)

let my_number = 1;
let my_number = 2;

可以使用与之前的变量相同的名字声明一个新变量:第一个变量被第二个变量"遮蔽"了(shadowed),本质是创建了一个新的变量,只不过名字相同.

shadowing 与 mut 的区别

let 遮蔽是创建新变量,可以改变类型(例如从 i32 变为 String);mut 是修改同一个变量的值,类型不可变.

数据类型

静态类型语言

Rust 是静态类型语言,编译时必须知道所有变量的类型.多数情况下编译器可以自动推断类型.

Rust 中的数据类型主要分为:

  • 标量类型(Scalar):表示一个单一的值
  • 复合类型(Compound):可以将多个值组合在一个类型中

标量类型

整数(Integer)

let my_number: i32 = 1;       // i = integer(整数), 32 = 32位
let eight_bit_integer: i8 = -128;
let another_one: u8 = 128;    // u = unsigned(无符号)

指定整数类型有两种方式:

let x: i32 = 5;   // 类型标注(Type Annotation)
let x = 5i32;     // 类型后缀(Type Suffix)
let y = 0u32;     // 后缀也可以直接跟在字面值后面
类型标注 vs 类型后缀

两种方式效果相同,都是告诉编译器该值的类型.类型标注更常见,类型后缀更紧凑.浮点数同样支持后缀:3.14f64.

Length 长度 Signed 有符号 Unsigned 无符号
8-bit i8 u8
16-bit i16 u16
32-bit i32(默认) u32
64-bit i64 u64
128-bit i128 u128
arch isize usize

i8: -2^7 至 2^7-1(即 -128 ~ 127) u8: 0 至 2^8-1(即 0 ~ 255)

整数除法会截断

两个整数相除时,结果仍是整数,小数部分会向零截断.例如 5 / 3 == 1,-5 / 3 == -1.需要小数结果时,至少一个操作数必须是浮点数,例如 5.0 / 3.0.

Number literals 数值字面值 示例
Decimal 十进制 98_222
Hex 十六进制 0xff
Octal 八进制 0o77
Binary 二进制 0b1111_0000
Byte(u8 only) 字节 b'A'

浮点(Floating Point)

let my_floating_number: f64 = 2.5;  // f = float(浮点数)
let other_float: f32 = 2.0;
  • f32: 4 字节
  • f64(默认): 8 字节
  • 都有符号(signed)

布尔(Boolean)

let this_is_true: bool = true;   // bool = boolean(布尔值)
let this_is_false = false;
  • 两个值:true,false
  • 1 字节

字符(Character)

let some_char: char = 'A';
  • 4 字节
  • 表示一个 Unicode 标量值(Unicode Scalar Value)

字符串(String)

Rust 有两种字符串类型:

let s1 = "hello";              // &str: 字符串切片,不可变
let s2 = String::from("hello"); // String: 可增长的字符串
let s3 = "hello".to_string();   // 等价于 String::from("hello")
&str vs String

&str 是字符串切片(引用),通常用于字符串字面量和函数参数.String 是堆上分配的可增长字符串,用于需要拥有或修改字符串的场景..to_string() 可以将 &str 转换为 String.

复合类型(Compound Type)

元组(Tuple)

let my_tuple = ('A', 1, 1.2);
let tup: (i32, f64, u8) = (500, 16.4, 1);
let (x, y, z) = tup; // 用模式一次解构三个元素
let five_hundred = tup.0;
  • 固定长度
  • 可含不同类型的元素
  • 通过 .索引 访问元素
元组 vs 数组

元组可容纳不同类型的元素,数组元素类型必须相同.元组访问使用 .0 .1 语法,数组使用 [0] 索引语法.

数组(Array)

let my_arr = [1, 2, 3];
let my_arr_typed: [i32; 3] = [1, 2, 3];  // [类型; 长度(Length)]
let a = [3; 5];
let first = my_arr[0];

match my_arr.get(10) {
    Some(value) => println!("{value}"),
    None => println!("索引越界"),
}

[3; 5] 表示创建包含 5 个元素,每个元素值为 3 的数组,等价于 [3, 3, 3, 3, 3].

  • 固定长度
  • 元素类型相同
数组越界访问

使用 array[index] 越界会在运行时 panic,Rust 不允许非法内存访问.索引来自用户输入等运行时数据时,优先使用 array.get(index):它返回 Option<&T>,可以用 match 显式处理 None,避免 panic.
