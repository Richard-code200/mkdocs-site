map、filter 与 collect

操作作用是否立即处理所有元素
map(f)用 f 的返回值替换每个元素,可改变类型否
filter(p)用 bool 决定保留与否,不替换原元素否
collect()消费迭代器并构造目标集合是,此处会收集剩余元素

|line| line.contains(query) 是闭包:|...| 中是参数,后面的表达式是返回值.这个闭包捕获并读取外部的 query,不需要转移查询字符串的所有权.对这里的 Item = &str,filter 的谓词接收对元素的引用,方法调用会处理相应解引用.

lines 与原文保持

str::lines() 返回原文中的行切片,不复制每行字符串.行分隔符不包含在返回的切片中;中间空行会产生空字符串,末尾换行不会额外增加一条空行:

不要随意 trim:原文的缩进和行首尾空格可能是数据.多行字符串字面量中的缩进也可能实际进入测试素材.

忽略大小写,但返回原始行

  • to_lowercase 创建新的 String;查询词在循环外转换一次,每行在判断时转换.
  • filter 只用小写结果判断,保留的仍是原始 line,所以大小写、顺序和缩进不变.
  • 返回借自临时小写 String 的切片既会丢失原文,也不能满足返回值的生命周期.

本项目的忽略大小写规则就是双方 to_lowercase 后比较,不等同于完整的 Unicode 大小写折叠方案.

enumerate:先编号,再过滤

enumerate 产生 (usize, 元素) 元组,编号从 0 开始.要保留原文件行号,顺序必须是:

(_, line) 忽略编号,只对文本判断;(index, line) 解构元组,将编号加 1 后组成新的元组.若先 filter 再 enumerate,得到的是“匹配结果中的序号”,会错误地变成 1 和 2.

忽略大小写并显示行号时,仍按这个顺序,仅把谓词换成小写比较.当前返回 Vec<(usize, &str)>,每行文字仍借自原文.
