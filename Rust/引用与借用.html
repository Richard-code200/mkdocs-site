什么是引用

引用(Reference)是 Rust 中一种不获取所有权的”借用”机制 — 它允许你使用某个值,但不会让调用者失去对它的所有权.

引用 vs 所有权

所有权(Owner)引用(&T)
修改值可以(如果是 mut)默认不可变
释放内存离开作用域时调用 drop不负责释放
数量限制同一时刻只有一个所有者可同时存在多个不可变引用
消耗方式Move / DropCopy(引用自身实现了 Copy)

可变引用 &mut T

可变引用的前提

要创建可变引用,原始变量必须声明为 mut.不可变变量不能产生可变引用.

为什么要有这些限制

同时读写同一块内存是数据竞争(Data Race)的温床:

  1. 两个或多个指针同时访问同一数据
  2. 至少有一个指针在写入
  3. 没有同步机制

Rust 的借用规则在编译期彻底消灭了数据竞争.

借用规则的形式化表述

在任意给定时间,以下二者只能选其一:

  • 任意多个不可变引用
  • 恰好一个可变引用

此外,所有引用必须始终是有效的(不能悬垂).

非词法生命周期(NLL)

早期借用检查较多地按照词法代码块推断借用有效期,上面的代码可能被拒绝.NLL(稳定用于 Rust 2018 edition)会根据控制流和最后一次使用推断借用何时不再约束后续代码,减少了很多不必要的编译错误.它没有改变变量由代码块决定的词法作用域.

NLL 的实际意义

NLL 让借用规则更智能,减少了大量”明明没冲突却编译不过”的情况.开发者在写代码时无需缩手缩脚,编译器会精确分析.

引用与函数

引用作为函数参数

函数签名即契约

通过参数类型就能判断函数的行为:

  • &T :函数只会读取数据
  • &mut T:函数可能会修改数据
  • T :函数会获取所有权,调用方之后不能再使用该值

切片:一种特殊的引用

字符串切片 &str

切片的本质是:一个指针 + 一个长度,不拥有底层数据.

数组切片 &[T]

切片是胖指针

切片&[T]和&str由两部分组成:

  1. 指针:指向数据起始地址
  2. 长度:元素个数

因此切片引用通常占两个机器字,而指向定长类型的普通引用 &T 通常占一个机器字;具体字节数随目标平台而变化.

引用与借用核心要点

引用机制让 Rust 在保持所有权系统零运行时开销的同时,实现了灵活,安全的数据访问. 掌握 &T 和 &mut T 的区别,遵守借用规则,理解切片,是写出地道的 Rust 代码的基础.
