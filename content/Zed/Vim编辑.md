Vim 编辑的重点是先确定范围，再选择操作。常用的组合包括修改单词、处理括号内的内容，以及重复上一次修改；在 Zed 中，还可以配合语言服务和语法结构完成重命名、参数编辑与代码导航。

> [!info] 适用范围
> 通用编辑部分面向 Vim / Neovim；标注为 Zed 的操作依赖其 Vim 模式、语言服务或语法支持。Surround 在 Zed 中内置，在 Vim / Neovim 中通常需要插件。
> 原稿整理日期为 2026-11-10。以下 Zed 键位按默认方案记录，不等于本机配置已逐项实测。

> [!warning] 本机自定义键位优先
> 本机键位见 [Zed 快捷键](Zed/快捷键.md)。其中 `c a` 已绑定为 Code Actions，会影响 `caw`、`ca(` 等以 `ca` 开始的文本对象操作；`g s a` / `g s d` / `g s r` 则是自定义 Surround 入口，也可能影响默认的 `gs` 行为。
> 符号重命名可优先使用本机的 `Space r n`，代码操作用 `Space c a`。下面的默认键位和本机自定义键位不要混记。

## 1. 核心思路：操作符 + 范围

常见组合：`[次数] + 操作符 + 文本对象或移动命令`。次数也可以放在操作符之后。

例如，`ciw` 依次按下 `c`、`i`、`w`：`c` 是 change，表示修改并进入插入模式；`i` 是 inside，不包含外围；`w` 是 word，表示单词。`d3w` 则删除连续三个 `w` 移动范围。

| 操作符 | 作用 | 示例 |
| --- | --- | --- |
| `c` | 修改并进入插入模式 | `ciw` |
| `d` | 删除 | `diw` |
| `y` | 复制（yank） | `yiw` |
| `v` | 进入字符可视选择 | `viw` |
| `>` / `<` | 增加 / 减少缩进 | `>ip` / `<ip` |
| `gU` / `gu` | 转大写 / 转小写 | `gUiw` / `guiw` |

`i` 是 inside，`a` 是 around。`iw` 通常不含相邻空格，`aw` 会连带适当空白。`w` 按 Vim 的单词规则划分；`W` 按空白分隔的 *WORD* 划分。

连续字母表示依次按键，例如 `ciw`；`Ctrl-r` 表示同时按下修饰键和字母。除特别说明外，编辑命令从普通模式开始。

## 2. 快速移动和定位

| 命令 | 作用 |
| --- | --- |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 |
| `w` / `b` / `e` | 下一单词开头 / 上一单词开头 / 单词结尾 |
| `0` / `^` / `$` | 行首 / 首个非空白字符 / 行尾 |
| `gg` / `G` | 文件开头 / 文件末尾 |
| `f<char>` / `F<char>` | 在当前行向右 / 向左查找字符，停在字符上 |
| `t<char>` / `T<char>` | 在当前行向右 / 向左查找字符，停在目标前一个 / 后一个字符上 |
| `;` / `,` | 按相同 / 相反方向重复最近一次 `f/F/t/T` 查找 |
| `%` | 跳到匹配的括号等配对位置 |
| `/pattern` / `?pattern` | 向文件末尾 / 开头方向搜索 |
| `n` / `N` | 沿原搜索方向 / 反方向继续搜索 |
| `*` / `#` | 向文件末尾 / 开头方向搜索光标下的单词 |

例如，`let result = calculate(first, second, third);`，光标在 `first` 开头时：

- `ct,`：修改到下一个逗号之前，保留逗号，进入插入模式。
- `dt,`：删除到下一个逗号之前，留在普通模式。
- `cf,`：修改到下一个逗号，包含逗号。
- `f)`：移动到本行的右括号。

## 3. 快速进入插入模式与编辑整行

| 命令 | 作用 |
| --- | --- |
| `i` / `a` | 在光标前 / 后插入 |
| `I` / `A` | 在本行首个非空白字符前 / 行尾插入 |
| `o` / `O` | 在下一行 / 上一行新建行并插入 |
| `dd` / `yy` / `cc` | 删除 / 复制 / 修改当前行 |
| `D` / `C` | 删除 / 修改至行尾，分别相当于 `d$` / `c$` |
| `S` | 修改整行，相当于 `cc` |
| `J` | 合并当前行和下一行 |
| `>>` / `<<` / `==` | 增加缩进 / 减少缩进 / 重新缩进当前行 |
| `5dd` / `3yy` | 删除五行 / 复制三行 |
| `x` / `s` | 删除当前字符 / 删除当前字符并插入 |
| `r<char>` / `R` | 替换一个字符 / 进入连续替换模式 |
| `xp` | 交换光标处与后一个字符的位置，常用于纠正打字顺序 |
| `~` | 切换光标下字符的大小写 |
| `p` / `P` | 在光标后 / 前粘贴；复制整行时按行粘贴 |

## 4. 文本对象：单词、段落、括号、字符串

| 命令 | 作用 |
| --- | --- |
| `ciw` / `caw` | 修改单词 / 修改单词及相邻空白 |
| `diw` / `daw` | 删除单词 / 删除单词及相邻空白 |
| `yiw` / `viw` | 复制 / 选中当前单词 |
| `ciW` | 修改当前以空白字符分隔的 WORD |
| `cip` / `dap` | 修改段落内部 / 删除段落，连带适当空白 |
| `ci(` / `ca(` | 修改圆括号内内容 / 修改圆括号及其内容 |
| `ci{` / `ca{` | 修改花括号内内容 / 修改花括号及其内容 |
| `ci[` | 修改方括号内内容 |
| `ci"` / `ca"` | 修改双引号内部 / 修改双引号及其内容 |
| `ci'` / `di(` / `yi{` | 修改单引号内部 / 删除圆括号内部 / 复制花括号内部 |

光标位于字符串内，执行 `ci"`：

```rust
println!("Hello, Rust!");
// 执行 ci" 后，字符串内容被清空，双引号保留：
println!("");
```

`ci{` 可以直接修改代码块内部，不必先用可视模式手动选择。包含外围的 `ca…` 操作在本机 Zed 中可能受前述自定义键位影响。

## 5. 基于移动范围组合编辑

| 命令 | 作用 |
| --- | --- |
| `dw` / `d3w` | 删除到下一单词起点 / 连续三个单词移动范围 |
| `d0` / `d^` | 删除到行首 / 删除到首个非空白字符 |
| `d$` / `c$` | 删除 / 修改至行尾 |
| `ct;` / `cf;` | 修改到下一个分号之前 / 包含分号 |
| `dt)` | 删除到下一个右括号之前 |
| `dG` | 删除到文件末尾 |
| `ggVG` | 从文件开头按行选中整个文件 |

先判断范围是“单词、括号、函数”，还是“从当前位置到某个字符”，再选文本对象或移动命令。

## 6. 撤销、重复、宏与批量替换

| 命令 | 作用 |
| --- | --- |
| `u` / `Ctrl-r` | 撤销 / 重做 |
| `.` | 重复上一次修改 |
| `qa` → 操作 → `q` | 将一系列操作录制到寄存器 `a` |
| `@a` / `10@a` | 执行宏 `a` 一次 / 十次 |
| `:%s/old/new/g` | 替换整个文件中每行的所有匹配 |
| `:%s/old/new/gc` | Vim / Neovim 中逐个确认替换；Zed 对 `c` 标志的支持需另行确认 |

例如，给下面三个变量添加相同前缀：

```rust
let apple = 1;
let banana = 2;
let orange = 3;
```

在 `apple` 开头按 `inew_`、`Esc`，再移到 `banana`、`orange` 的开头分别按 `.`，就会重复插入 `new_`。`.` 重复的是相同编辑内容，不会自动生成不同的新名字。

宏适合“移动 + 删除 + 插入”等多步重复编辑；简单修改优先用 `.`。

## 7. Surround：快速操作包围符号

> [!info] 内置功能与插件的区别
> Zed Vim 模式内置 `ys` / `cs` / `ds`。原生 Vim 不内置这些键位；Neovim 通常需要 `nvim-surround` 等插件。
> 下表是默认 Surround 操作。本机另外配置了 `g s a` / `g s d` / `g s r`，具体上下文见 [Zed 快捷键](Zed/快捷键.md)。

| 命令 | 作用 |
| --- | --- |
| `ysiw"` | 为当前单词添加双引号 |
| `ysiw)` | 添加紧凑圆括号：`word` → `(word)` |
| `ysiw(` | 添加带内侧空格的圆括号：`word` → `( word )` |
| `cs"'` | 将外围双引号改成单引号 |
| `ds"` | 删除外围双引号 |
| `cs)]` | 将圆括号改成紧凑方括号 |
| `cs([` | 将圆括号改成内侧带空格的方括号 |

Rust 字符串使用 `cs"'` 后可能变成不合法的 Rust 代码；这里演示的是包围符号的文本变换，不是代码转换。

## 8. Zed 专用：智能重命名与多光标

同名文本不一定是同一变量的引用。修改符号名称时，优先使用语言服务的重命名，而不是直接多选所有同名文本。

| 默认键位 | 作用 | 用途 |
| --- | --- | --- |
| `cd` | 通过语言服务器重命名符号 | 变量、函数、类型重命名 |
| `ga` | 选中当前单词的全部匹配文本 | 批量修改字面文本 |
| `gl` / `gL` | 添加下一个 / 上一个同名单词选区 | 逐个扩大多光标选择 |
| `g>` / `g<` | 跳过最近的匹配选择并向后 / 向前查找 | 排除不需要修改的位置 |
| `gA` | 可视模式中在每行末添加光标；普通模式中查看引用 | 多行编辑 / 引用查询，依赖上下文 |

```rust
fn main() {
    let count = 10;
    println!("{count}");
    let total = count + 5;
}
```

将 `count` 重命名为 `number`，默认方案下把光标放在 `count` 上按 `cd`，再输入新名字；本机可用 `Space r n`。rust-analyzer 会根据语义识别引用。`ga` 是文本层面的多选，可能影响注释、字符串或其他作用域中同名的内容。

## 9. Zed 专用：Tree-sitter 结构化编辑

这些操作依赖对应语言的语法结构定义。Rust 等支持良好的语言更适合使用，实际范围仍与光标位置和语言支持有关。

| 默认键位 | 作用 |
| --- | --- |
| `via` / `cia` / `daa` | 选中参数 / 修改参数 / 删除参数及适当的分隔符 |
| `vaf` / `vif` | 选中整个函数 / 函数内部 |
| `daf` / `cif` | 删除整个函数 / 修改函数内部 |
| `vai` | 按当前缩进范围及其前一行选中，即 `a i` 对象 |
| `vii` | 选中当前缩进层级，即 `i i` 对象 |
| `]m` / `[m` | 下一个 / 上一个函数或方法 |
| `]M` / `[M` | 下一个 / 上一个函数或方法结尾 |
| `] ]` / `[ [` | 下一个 / 上一个 section / 定义边界 |
| `[x` / `]x` | 扩大 / 缩小语法节点选择 |
| `gcc` / 可视模式 `gc` | 注释或取消注释一行 / 选中范围，Zed 内置 |

语法级操作需要与经典 Vim 的通用文本对象区分。`daf` 等命令中的 `a` 也属于文本对象，并非插入模式命令。

## 10. Zed 专用：语言服务与代码导航

| 默认键位 | 功能 |
| --- | --- |
| `gd` / `gD` | 跳转到定义 / 声明 |
| `gy` / `gI` | 跳转到类型定义 / 实现 |
| `gA` | 普通模式中查看所有引用 |
| `gs` / `gS` | 查找当前文件 / 整个项目中的符号 |
| `]d` / `[d` | 下一个 / 上一个诊断 |
| `gh` | 查看诊断或悬浮信息 |
| `g.` | 打开 Code Actions 菜单 |
| `Ctrl-x Ctrl-o` | 插入模式中打开补全菜单 |
| `Ctrl-x Ctrl-l` | 插入模式中打开 Code Actions 菜单 |

Zed 的语言服务能力不属于 Vim / Neovim 的原生默认键位。尤其是 `gs`，需要留意本机 `g s …` 自定义绑定的覆盖；本机的常用入口包括 `g r` 查看引用、`Space c a` 打开代码操作。

## 11. Zed Vim 模式配置与兼容性

在 Zed 的 `settings.json` 中开启 Vim 模式，配置示例：

```json
{
  "vim_mode": true,
  "vim": {
    "default_mode": "normal",
    "use_system_clipboard": "on_yank",
    "toggle_relative_line_numbers": true,
    "highlight_on_yank_duration": 200
  }
}
```

- `use_system_clipboard` 取值包括 `always`（默认）、`on_yank`、`never`。
- Zed 模拟常见 Vim 操作，但不是完整的 Vim / Neovim 运行时，也不能直接运行 Neovim 的 Lua 插件。
- Zed 的块选择使用多光标系统，宏使用 Zed 自身的录制能力。
- `:%s` 的正则细节不同：Vim 中捕获组常写作 `\(...\)`，替换引用是 `\1`；Zed 对应正则引擎的写法是 `(...)`、`$1`。Zed 对部分 Vim 风格替换命令提供转换，复杂规则仍需确认。
- 键位无响应时，先检查当前模式、语言支持、Zed 版本和 `keymap.json` 的自定义覆盖。

> [!warning] 配置示例不是完整配置文件
> 上面的 JSON 只展示 Vim 相关设置。需要合并到现有设置中，不要直接覆盖整份 `settings.json`。这里不修改本机配置，也不将示例当成当前配置。

## 12. 日常练习优先级

按操作类型逐步练习，不必一次记住所有键位：

1. **精准定位**：`A`、`I`、`f/t`、`;`、`%`、`*`。
2. **范围编辑**：`ciw`、`ci"`、`ci(`、`ci{`、`ct,`。
3. **重复与批量**：`.`、`qa` / `@a`、`:%s`。
4. **结构编辑**：`ys` / `cs` / `ds`、`cia`、`vaf`、`cif`。
5. **Zed 语义操作**：`cd`（本机可用 `Space r n`）、`ga`、`gd`、`gI`、`]d`、`g.`。

先确定要编辑的范围，再决定移动和操作的组合。
