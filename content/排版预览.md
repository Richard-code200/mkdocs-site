## 代码字体与配色

代码主体使用 **MonaspiceNe**，注释使用 **MonaspiceRn Italic**；代码中的中文仍使用更纱黑体。高亮由 Shiki 构建时生成，使用原站色板映射的自定义主题。

```rust
// 注释使用 Radon 斜体；中文使用更纱黑体。
fn main() {
    let message: &str = "学到一点，就记录一点";
    let ready = true;
    if ready && message.len() >= 1 {
        println!("{}", message);
    }
}
```

```bash
# 查找源码并搜索固定字符串
find src -type f -name '*.rs'
rg -n -F 'Result<T, E>' src

```
