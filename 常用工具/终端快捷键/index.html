终端快捷键

本文记录本机 Ghostty、tmux 和 zsh 环境中的常用快捷键，依据 2026-09-16 的本地配置、Ghostty 键位列表、tmux 运行时绑定及 zsh 键位查询整理。zsh 启用了 zsh-vi-mode、fzf、fzf-tab 和自动建议；当前 tmux 前缀为 Ctrl-a，复制模式使用 Vi 键位。

按键约定

  • Ctrl、Shift、Alt 是修饰键，Ctrl-Shift-c 表示同时按下三个键。
  • 空格分隔表示依次按下，例如 Ctrl-a c：先按 Ctrl-a，松开后再按 c。
  • 本文直接写出 tmux 前缀 Ctrl-a，不再使用默认的 Ctrl-b。
  • 大写单键需要配合 Shift，例如 Ctrl-a H 表示前缀后按 Shift-h。
  • h/j/k/l 等写法表示四个可选按键，不是输入斜杠。
  • Ghostty 处理终端窗口、标签与系统剪贴板；tmux 管理会话、窗口和窗格；zsh 处理命令行输入。应结合各表的上下文使用。

Ghostty：窗口、显示与剪贴板

以下包括本机自定义绑定和当前版本仍保留的默认绑定；不需要 tmux 前缀。

复制、搜索与显示

快捷键 功能
Ctrl-Shift-c 将选中的文本复制到系统剪贴板
Ctrl-Shift-v 从系统剪贴板粘贴
Ctrl-Shift-a 全选终端文本
Ctrl-Shift-f 搜索终端文本
Esc 结束 Ghostty 搜索，限搜索上下文
Ctrl-Shift-= 增大字号，本机自定义绑定
Ctrl-- 减小字号，即 Ctrl 加减号键
Ctrl-0 恢复默认字号
Shift-PageUp / Shift-PageDown 向上 / 向下滚动 Ghostty 的历史输出
Shift-Home / Shift-End 滚动到 Ghostty 历史顶部 / 底部
Ctrl-Shift-p 打开或关闭命令面板
Ctrl-, 打开 Ghostty 配置
Ctrl-Shift-, 重新加载 Ghostty 配置

copy-on-select = false，因此仅用鼠标选中文本不会自动复制。在 tmux 中查看某个窗格的历史输出时，优先使用 Ctrl-a [，避免混淆 Ghostty 与 tmux 各自保存的历史。

窗口、标签与原生分屏

快捷键 功能
Ctrl-Shift-n 新建 Ghostty 窗口
Ctrl-Shift-t 新建 Ghostty 标签
Ctrl-Tab / Ctrl-Shift-Tab 下一个 / 上一个标签
Alt-1 至 Alt-8 切换到指定标签
Alt-9 切换到最后一个标签
Ctrl-Shift-w 关闭当前标签
Ctrl-Shift-q 退出 Ghostty
Ctrl-Shift-o / Ctrl-Shift-e 向右 / 向下创建 Ghostty 原生分屏
Ctrl-Alt-方向键 切换 Ghostty 原生分屏
Ctrl-Shift-Enter 放大或恢复 Ghostty 当前分屏
Ctrl-Enter 切换全屏

本机还将 Shift-Enter 配置为发送换行字符 \n。它不是通用的“只换行不执行”：zsh 可能将该字符作为接受命令处理，交互程序则按自身规则解释。

快捷键 功能
Ctrl-a d 分离当前客户端，保留会话与其中的程序
Ctrl-a s 打开会话树，选择会话
Ctrl-a w 打开窗口树，选择窗口
Ctrl-a $ 重命名当前会话
Ctrl-a c 新建窗口

历史输出与复制模式

先按 Ctrl-a [ 进入复制模式。以下按键在复制模式中直接使用，不需要再次输入前缀。

快捷键 功能
h/j/k/l 或方向键 移动复制光标
Ctrl-u / Ctrl-d 向上 / 向下翻半页
Ctrl-b / Ctrl-f 向上 / 向下翻一页
g / G 跳到历史顶部 / 底部
0 / $ 跳到行首 / 行尾
? / / 向上 / 向下搜索，输入内容后按 Enter
n / N 沿当前搜索方向继续 / 反向搜索
Space 开始选择文本
V 选择整行
v 切换矩形选择
Enter 复制选区并退出复制模式
Esc 清除选区
q 退出复制模式

退出复制模式后，使用 Ctrl-a ] 粘贴 tmux 缓冲区，或使用 Ctrl-a = 打开缓冲区列表。tmux 缓冲区与系统剪贴板是不同的机制，是否同步还取决于终端剪贴板支持与 tmux 配置。

例如，复制之前的一段输出：Ctrl-a [ → ? 搜索关键词 → Space 开始选择 → 移动光标 → Enter 复制 → Ctrl-a ] 粘贴。

插件与配置维护

快捷键 功能
Ctrl-a Ctrl-s 使用 tmux-resurrect 保存会话状态
Ctrl-a Ctrl-r 使用 tmux-resurrect 恢复已保存的会话状态
Ctrl-a I 使用 TPM 安装配置中声明的插件
Ctrl-a U 使用 TPM 更新插件
Ctrl-a R 重新加载 ~/.tmux.conf，并显示提示

tmux-continuum 当前配置为每 15 分钟自动保存，并在 tmux 服务启动时自动恢复。会话恢复主要用于重建窗口、布局和受支持的程序，不等于恢复任意进程的内存状态。

zsh：命令行编辑与历史搜索

插入模式

当前使用 Vi 键位。输入命令时通常处于插入模式，按 Esc 切换到普通模式。

快捷键 功能
Ctrl-e / End 移动到行尾；自动建议可见时也可能接受建议
Home 移动到行首
Ctrl-a zsh 本身绑定为行首；在 tmux 中需按 Ctrl-a Ctrl-a 才能传入
Ctrl-b / Ctrl-f 向左 / 向右移动一个字符
Ctrl-w 删除光标前的一个单词
Ctrl-u 删除当前输入缓冲区开头到光标之间的内容，本机由 zsh-vi-mode 实现
Ctrl-k 删除光标到行尾的内容
Backspace / Delete 删除光标前 / 光标处的字符
Ctrl-y 粘贴 zsh 剪切缓冲区中的内容，并非系统剪贴板
Ctrl-_ 撤销一次编辑
Ctrl-l 清屏并重绘命令行，不删除历史命令
Ctrl-p / Ctrl-n 上下移动或搜索历史；单行输入时可按已输入前缀查找
↑ / ↓ 上下移动或浏览历史命令
→ 向右移动；在输入末尾有灰色自动建议时接受建议
Tab 触发 fzf-tab 补全，筛选命令、路径或参数候选项

Ctrl-u 的当前插件实现直接修改输入缓冲区，不应假定被删除的内容一定可以用 Ctrl-y 粘回。Ctrl-d 当前绑定为列出补全候选项，也不应直接套用其他 Shell 中“按一下退出”的习惯；退出可输入 exit。

fzf 快捷入口

快捷键 功能 典型用法
Ctrl-r 模糊搜索历史命令，将选中命令放回输入行 搜索以前执行过的 git 命令
Ctrl-t 搜索文件或目录，将选中路径插入输入行 先输入 nvim，再选择文件
Alt-c 搜索目录并直接切换过去 在项目目录之间跳转

在这些 fzf 选择界面中，输入关键词缩小范围，使用 ↑ / ↓ 选择，Enter 确认，Esc 或 Ctrl-c 取消。Ctrl-r 选中的命令通常仍需再次按 Enter 才执行。

前台程序与任务控制

快捷键或命令 功能 上下文
Ctrl-c 发送中断信号，通常用于停止当前命令 前台程序，具体行为取决于程序
Ctrl-z 暂停前台任务，将控制权交回 Shell 支持作业控制的终端程序

Ctrl-z 是暂停任务；Ctrl-a d 是分离 tmux 客户端并让会话继续运行，两者用途不同。

上下文差异与配置维护

容易混淆的快捷键
  • Ctrl-a a 切换到上一个 tmux 窗口；Ctrl-a Ctrl-a 才是向窗格内程序发送字面量 Ctrl-a。
  • Ctrl-a q 在本机直接关闭窗格，并不是默认配置中的显示窗格编号；复制模式里的单独 q 则是退出复制模式。
  • zsh 普通模式的 / 向较早历史搜索；tmux Vi 复制模式的 / 则向下搜索输出。
  • Ctrl-r 在 zsh 中搜索历史；Ctrl-a Ctrl-r 调用 tmux-resurrect 恢复会话。
  • Ghostty 的标签、原生分屏与 tmux 的窗口、窗格分别管理；切换时需要使用对应层的快捷键。
  • 在 Zed 内置终端中，外层编辑器可能先截获按键，参见 Zed 快捷键。

配置来源：

  • Ghostty：~/.config/ghostty/config.ghostty。
  • tmux：~/.tmux.conf 及插件绑定，以正在运行的服务中的键表为准。
  • zsh：~/.zshrc，其中先初始化 zsh-vi-mode，再注册 fzf 与自定义历史键位。

配置变化后，可在交互终端中重新核对：

# Ghostty 当前配置对应的快捷键
ghostty +list-keybinds

# tmux 前缀、复制模式及实际绑定
tmux show-options -gv prefix
tmux show-options -wAv mode-keys
tmux list-keys -T prefix
tmux list-keys -T copy-mode-vi

# zsh 当前主键表与不同模式的绑定
bindkey -lL main
bindkey -M viins
bindkey -M vicmd

zsh 插件可能在提示符出现或首次进入某个模式时继续注册绑定；因此排查按键问题时，应同时检查插件状态、当前模式和外层终端是否截获按键。
