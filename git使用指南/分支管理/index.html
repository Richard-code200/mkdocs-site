分支管理

分支基本操作

# 查看分支
git branch                    # 本地分支
git branch -r                 # 远程分支
git branch -a                 # 所有分支
git branch -v                 # 显示最后一次提交

# 创建分支
git branch <branch-name>
git branch <branch-name> <commit-id>  # 基于指定提交创建

# 切换分支
git checkout <branch-name>
git switch <branch-name>      # Git 2.23+ 推荐

# 创建并切换分支
git checkout -b <branch-name>
git switch -c <branch-name>   # Git 2.23+ 推荐

# 重命名分支
git branch -m <old-name> <new-name>

# 删除分支
git branch -d <branch-name>   # 安全删除(已合并)
git branch -D <branch-name>   # 强制删除(未合并)

合并分支

# 将指定分支合并到当前分支
git merge <branch-name>

# 合并选项
git merge --no-ff <branch-name>     # 禁用快进合并，保留分支历史
git merge --squash <branch-name>    # 压缩所有提交为一个

# 取消合并（合并冲突时）
git merge --abort

处理合并冲突

# 1. 当合并出现冲突时
git status  # 查看冲突文件

# 2. 手动编辑冲突文件，解决冲突标记
# <<<<<<< HEAD
# 当前分支的内容
# =======
# 要合并分支的内容
# >>>>>>> branch-name

# 3. 标记冲突已解决
git add <resolved-file>

# 4. 完成合并提交
git commit -m "解决合并冲突"

Rebase(变基)

# 将当前分支变基到目标分支
git rebase <target-branch>

# 交互式 rebase（整理提交历史）
git rebase -i <commit-id>
git rebase -i HEAD~3  # 整理最近3次提交

# 解决冲突后继续
git rebase --continue

# 中止 rebase
git rebase --abort

分支策略示例

main 分支：主分支，用于生产环境
develop 分支：开发主分支
feature/* 分支：功能开发分支
release/* 分支：发布准备分支
hotfix/* 分支：紧急修复分支
