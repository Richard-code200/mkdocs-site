# 字体资源维护

## 字体搭配

参考 [Monaspace](https://monaspace.githubnext.com/) 的混合字体设计，使用其 Nerd Fonts 版本 Monaspice：

| 用途 | 字体 |
| --- | --- |
| 正文、导航中的西文 | MonaspiceAr（Argon） |
| 标题中的西文 | MonaspiceXe（Xenon）Bold |
| 代码主体 | MonaspiceNe（Neon） |
| 代码注释、文档字符串 | MonaspiceRn（Radon）Italic |
| 中文及西文字体缺失的字符 | Sarasa Term SC Regular / Bold |

字体从站点自身加载，不依赖访客安装字体或第三方 CDN。中文斜体使用浏览器合成，未另行打包大型中文斜体文件。

本次源字体版本：Monaspice 1.200 / Nerd Fonts 3.4.0，Sarasa Term SC 1.0.43。Monaspice 的西文字宽为 0.62em，Sarasa 汉字为 1em；混排优先保持字号与可读性，不承诺汉字恰好占两个 Monaspice 字符宽度。纯代码的等宽排列不受影响。

## 重新生成

在仓库根目录运行。需要 Python、`fonttools[woff]`（包含 WOFF2 转换所需的 Brotli 支持）以及完整的源字体目录：

```sh
python scripts/build_fonts.py \
  --monaspice "$HOME/.local/share/fonts/MonaspaceNerd" \
  --sarasa "$HOME/.local/share/fonts/SarasaTermSC"
mkdocs build
```

脚本生成 `docs/assets/fonts/*.woff2` 和 `docs/assets/css/font_faces.css`，保留 OpenType 布局特性与字体内嵌元数据。字号、行距、字体用途分别在 `body_fonts.css`、`code_fonts.css` 中维护。

西文子集保留 U+0000–2FFF 及 U+FB00–FB06 中源字体支持的字符，覆盖常见编程符号、拉丁、希腊与西里尔字母；不打包额外的 Nerd Fonts 私用区图标。站点图标仍由既有图标资源提供。

Sarasa 保留源字体支持的全部字符，先将现有笔记用字每 1024 字分包，剩余字符每 2048 字分包。CSS 通过互不重叠的 `unicode-range` 按页面实际用字加载，因此新笔记出现新汉字也无需重新生成；重新生成只是重新优化常用字的分组。

生成资源纳入版本控制，普通 MkDocs 构建不需要安装字体处理工具。更新源字体时需一并核对许可证；更改分包策略后，确认旧分包是否还被生成的 CSS 引用，再清理过期文件。
